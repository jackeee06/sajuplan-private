# 부재중 상담요청 & 다시 연결 (전화/채팅 요청 → 콜백)

## 한 줄로 답하면
**부재중(자리비움)인 상담사에게도 고객이 "전화 요청 / 채팅 요청"을 남길 수 있고, 상담사가 상담가능을 켜는 순간 그 고객들에게 "지금 상담 가능해졌어요" 알림이 자동으로 갑니다. 상담사 대시보드 맨 위에는 "지금 상담 켜기" 카드로 누가 기다리는지 바로 보입니다.**

## 전체 흐름 (고객 → 상담사 → 다시 연결)

```
① 고객이 부재중 상담사에게 요청
   상담사 카드/상세에서 "전화 요청" 또는 "채팅 요청" 버튼 (둘 중 선택)
   → 상담사에게 알림 발송 (카톡 + 푸시 + 알림함)
        "○○ 님이 전화 상담을 기다렸어요"

② 상담사가 알림의 [바로가기] 클릭
   → 상담사 대시보드(마이페이지)로 이동
   → 맨 위에 "지금 상담 켜기" 카드 노출
        "○○ 님이 전화 상담을 기다려요 · 3분 전  (외 2명)"

③ 상담사가 "지금 상담 켜기" 한 번 클릭
   → 상담가능 ON (원래 하던 채널 그대로)
   → 기다리던 고객 전원에게 "상담 가능해졌어요" 콜백 알림 자동 발송

④ 고객이 콜백 알림 받고 다시 접속 → 정상 상담
```

## 왜 "자동 연결"이 아니라 "다시 알림"인가

상담사가 상담가능을 켠다고 **고객에게 자동으로 전화가 걸리거나 채팅이 열리지는 않습니다.** 사주플랜은 연결의 시작이 **항상 고객 쪽**이기 때문입니다.
- **전화상담**: 고객이 070 번호로 **겁니다** (상담사가 고객에게 자동 발신 불가 — 전화망 구조)
- **채팅상담**: 고객이 신청하고 **코인이 차감되며** 방이 열립니다 (상담사가 먼저 방을 못 엶)

그래서 "상담사가 켜짐 → 고객에게 다시 알림 → 고객이 돌아와 연결"이 구조상 가능한 최선입니다. 상담사가 요청을 본 시점엔 이미 고객이 떠났을 수 있으므로(대다수), **"지금 접속하면 바로 연결" 같은 문구는 쓰지 않습니다.**

## 채널(전화/채팅)을 나눠 요청받는 이유

부재중일 땐 전화가 울리지 않으므로, 상담사는 화면 알림으로만 무슨 요청인지 압니다. 그래서 고객이 **전화인지 채팅인지 골라** 요청하고, 알림 문구에 "전화 상담" / "채팅 상담"이 그대로 표시됩니다.

## 같은 고객이 여러 번 눌러도 = 1건

같은 고객이 같은 상담사에게 **24시간 안에** 다시 요청하면 새 알림이 가지 않습니다(중복 차단). 목록/카드에는 "요청됨"으로 표시됩니다. 여러 기기에서 동시에 눌러도 요청은 1건, 알림도 1번만 나갑니다.

## "부재중"에는 예약중(RESV)도 포함됩니다

상담사 상태가 **자리비움(ABSE)** 이든 **예약중(RESV)** 이든, 고객 화면엔 똑같이 "요청" 버튼이 뜨고 요청을 받습니다. 상담사가 나중에 상담가능으로 켜면 두 경우 모두 콜백 알림이 나갑니다.

## 이런 상황을 보셨나요?

### 상담사: "알림 바로가기를 눌렀는데 회원 홈으로 튕겼어요"
→ **예전 버그였고 고쳤습니다.** 이제 [바로가기]는 상담사 대시보드로 정확히 이동합니다.

### 상담사: "상담 켰는데 고객이 안 들어와요"
→ 정상입니다. 켜는 순간 고객에게 "지금 가능" 알림이 나갔고, **고객이 그 알림을 보고 다시 들어와야** 연결됩니다. 즉시 자동 연결은 (위 설명대로) 구조상 안 됩니다.

### 상담사: "전화만 하는데 '지금 상담 켜기'가 채팅도 켜나요?"
→ 아니요. **원래 하던 채널 그대로** 켭니다. 전화만 하던 분은 전화만 켜집니다.

### 고객: "요청했는데 아무 반응이 없어요"
→ 상담사가 아직 상담가능을 켜지 않은 상태입니다. 상담사가 켜면 "상담 가능해졌어요" 알림이 갑니다. (24시간 지나면 요청은 자동 만료)

## 이건 정상인가요? 에러인가요?

| 상황 | 답변 |
|---|---|
| 부재중 상담사 카드에 "전화 요청/채팅 요청" 2버튼 | ✅ 정상 (2026-07-03 도입) |
| 상담사가 켜도 고객에게 자동 전화/채팅 연결 안 됨 | ✅ 정상 (연결 시작은 항상 고객측) |
| 상담사가 켜는 순간 대기 고객에게 콜백 알림 | ✅ 정상 |
| 같은 고객 24시간 내 재요청 시 알림 안 감 | ✅ 정상 (중복 차단) |
| 예약중(RESV) 상담사도 요청 받고 콜백 감 | ✅ 정상 |
| [바로가기]가 회원 홈으로 튕김 | ❌ **사고** (딥링크 점검 — 지금은 수정됨) |
| 상담 켰는데 대기 고객에게 콜백이 안 감 | ❌ **사고** (콜백 로직 점검) |

## 운영자가 확인하는 위치

| 확인 항목 | 위치 |
|---|---|
| 상담사가 받은 요청 발송 이력 | 서버 로그 `[requestConsult]` |
| 콜백 발송 이력 | 서버 로그 `[availableCallback]` |
