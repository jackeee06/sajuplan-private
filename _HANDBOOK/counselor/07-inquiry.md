# 상담사 고객센터 문의는 어떻게 처리하나요?

## 한 줄로 답하면
**상담사가 마이페이지에서 운영팀에 1:1 문의를 남기면 → 관리자 "상담사 고객센터 문의" 화면에서 답변한다.** (회원 문의와 별개. 상담사↔운영팀 채널)

## 흐름
1. **상담사**: 마이페이지 → 고객센터 문의하기 → 분류·제목·내용(+사진) 작성
2. 작성 즉시 **운영자에게 알림** 발송 ("상담사 ○○ 님이 새 문의를 남겼습니다")
3. **운영자**: 사이드바 → 기타 → **상담사 고객센터 문의** → 목록(대기/답변완료 필터) → 상세 → 답변 등록
4. 답변 등록 시 상태가 **답변완료**로 바뀌고, 상담사 마이페이지에서 답변 확인 가능

## 상태 2가지

| status | 의미 |
|---|---|
| `pending` (대기) | 상담사가 작성, 운영자 답변 전 |
| `answered` (답변완료) | 운영자 답변 등록됨 |

- 답변을 **삭제**하면 다시 `pending` 으로 돌아간다.
- 답변자 이름은 개인명이 아니라 **"운영팀"** 으로 고정 표기된다.

## 이건 정상인가요? 에러인가요?

| 상황 | 답변 |
|---|---|
| 상담사 문의 작성 → 운영자에게 알림 도착 | ✅ 정상 |
| 답변 등록 → 상담사 마이페이지에 답변 표시 | ✅ 정상 |
| 답변자 이름이 개인명 아닌 "운영팀" | ✅ 정상 (의도된 고정값) |
| 상담사 문의인데 회원 문의(상담문의) 메뉴에 안 보임 | ✅ 정상 (테이블·화면 별개) |
| 작성했는데 운영자 알림 0건 | ⚠️ 알림 발송 점검 (문의 자체는 저장됨) |

## 운영자가 확인하는 위치

| 확인 항목 | 메뉴 위치 |
|---|---|
| 상담사 문의 목록·답변 | 사이드바 → 기타 → 상담사 고객센터 문의 |
| 상담사가 보는 화면 | (사용자 앱) 상담사 마이페이지 → 고객센터 문의하기 |
