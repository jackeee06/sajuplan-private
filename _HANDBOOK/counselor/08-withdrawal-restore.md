# 탈퇴한 상담사가 다시 하려고 하는데 승인이 안 돼요 (계정 복구)

## 한 줄로 답하면
**탈퇴한 상담사는 새 계정으로 다시 만들지 말고 "기존 계정을 복구"한다.** 그래야 등급·m2net 연결·후기·수익금·단골·정산 이력이 그대로 살아남고, 식별자 중복 충돌도 안 난다.

## 왜 "복구"가 정답인가 (재가입으로 새로 만들면 생기는 문제)

상담사가 탈퇴(`left_at` 마킹)한 뒤 같은 전화로 **재가입하면 계정이 둘로 갈라진다**:
- 옛 상담사 계정: 탈퇴 상태지만 **dtmfno·csrid·m2net 등록을 그대로 쥐고 있음**
- 새 계정: 일반 회원으로 새로 생김

이 상태에서 새 계정을 상담사로 승인하면 →
- **m2net 중복 등록 충돌** (옛 계정이 그 번호로 아직 등록돼 있음)
- **후기·수익금·단골·정산 원장이 옛 계정에 남아 단절**
- 승인 자체가 *"같은 휴대폰으로 다른 아이디 회원이 있습니다"* 같은 안전장치에 막혀 실패

그래서 **옛 계정을 되살리는 게** 충돌도 없고 이력도 보존된다.

## 어떻게 복구하나 (2가지 경로)

### ① 상담사 상세에서 복구 버튼
- 관리자 → 회원현황 → 상담사 리스트 → 해당(탈퇴) 상담사 상세
- 상단에 노란 배너 + **"🔄 이 계정 복구"** 버튼 → 원클릭 복구
- 복구 시: 탈퇴 해제 + 같은 전화의 중복 새 계정 자동 정리

### ② 신청 승인 화면에서 자동 감지
- 상담사 신청을 승인하려는데, **같은 전화의 탈퇴 상담사가 있으면**
- 승인 화면 상단에 *"이 전화번호의 탈퇴 상담사 계정이 있습니다 — 새로 만들지 말고 복구하세요"* 배너 + **"🔄 기존 계정 복구"** 버튼
- 누르면: 옛 계정 복구 + 이 신청 자동 취소처리 + 상담사 상세로 이동

## 복구 후 본인은 어떻게 로그인하나
- **옛 아이디로 로그인**한다 (재가입한 새 아이디 아님).
- 비밀번호를 모르면 → **비밀번호 찾기**(휴대폰 인증 → 임시비번 알림톡) 정상 동작, 또는 관리자가 상담사 상세에서 **비밀번호 변경**으로 발급.
- 복구 후 상태는 **부재중**일 수 있으니, 상담사 마이페이지에서 **상담가능 토글 ON**.

## 이건 정상인가요? 에러인가요?

| 상황 | 답변 |
|---|---|
| 탈퇴 후 재가입한 상담사 승인이 막힘 | ✅ 정상 (안전장치 — 복구로 처리) |
| 복구하면 옛 csrid·dtmfno·후기·수익금 그대로 | ✅ 정상 (그게 복구의 목적) |
| 복구 후 통화/채팅 라우팅 바로 됨 | ✅ 정상 (탈퇴해도 m2net 등록은 안 풀림) |
| 복구 시 같은 전화의 새 계정이 탈퇴 처리됨 | ✅ 정상 (한 사람 한 계정 — 중복 정리) |
| 새 계정으로 받았던 가입 코인이 사라짐 | ✅ 정상 (중복 계정 정리에 따른 것) |
