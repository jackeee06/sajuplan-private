# 운세 포털 — 공유 프로필 & 만세·타로 임베드

## 공유 프로필 — "한 번 입력 → 모든 운세 자동"
- 홈 상단 **"내 정보"**에서 생년월일+성별을 **한 번만** 입력하면 13개 타일 전부에 자동 적용.
  - 띠·별자리는 생년월일에서 **자동 계산**(따로 고를 필요 없음).
  - 궁합은 "나"가 자동 채워져 **상대만** 입력.
- **필수 = 생년월일·성별**(게으른 사람 배려), **선택 = 이름·태어난 시각(시간 모름 가능)·출생지**(만세력 정밀·연동용).
- 강제 아님 — 안 넣어도 둘러보기 가능, 가볍게 권유만("한 번만 입력하면 계속 사용할 수 있어요").
- 입력 후엔 **만세력처럼 접힌 요약 카드**(이름 + "1990.06.15 오전 7:20 · 여성 · 말띠 · 쌍둥이자리" + [정보 수정하기]·[초기화]).
- 저장은 기기(브라우저)에. 추후 사주플랜 로그인 시 회원 생일 자동 채움(SSO)으로 확장 예정.

## 입력 방식 — 만세력식 타이핑
- 날짜·시각은 휴대폰 달력 휠 대신 **숫자 타이핑 자동 포맷**: 날짜 `1990/06/15`, 시각 `07:20`(모바일 숫자 키패드). 양력 기준.

## 만세력·타로 — 포털 안에서 열림(복사 아님)
- 만세력·타로 타일을 누르면 **포털 안 iframe**으로 진짜 사이트가 열리고, 상단 "‹ 운세 포털" 로 돌아옴.
- 기존 manse·tarot.sajuplan.com을 **건드리지 않고 그대로 재사용**(복사 X) → 만세력을 고치면 포털에도 자동 반영(유지보수 한 곳).
- **만세력 자동 연동**: 내 정보를 넣어두면 만세력 타일을 눌렀을 때 **입력 없이 사주 명식 결과가 바로** 뜬다(재입력 없음). 정밀한 시간·출생지는 만세력 안에서 보강 가능.

## 안전·정책
- 모든 무료 운세 = 재미·참고용. 깊은 풀이는 상담 유도(완결적 AI 풀이 금지).
- 로또 판매 아님 / "당첨 보장·예측" 금지 / 19세·과몰입 면책. 사람 이름 빨강·핑크 금지.
