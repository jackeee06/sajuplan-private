# 운세 포털 타일 — 엔진 기술 (결정론 함수)

엔진 패키지 `@portal/engine` (`portal/packages/engine/src/`). 전부 순수·결정론적, **Math.random·Date 미사용**(날짜·랜덤은 호출부=UI가 시드로 전달). 빌드: `npm run build -w @portal/engine`(web이 dist 참조 → 엔진 수정 시 tsc 빌드 먼저).

## 모듈별 함수
- `seed.ts`: `hashString`(FNV-1a) / `mulberry32`(시드 PRNG) / `pickUnique(seed,count,max)`(중복없는 N개 오름차순). 결정성의 토대.
- `lotto.ts`: `destinyNumbers(birth,gender)`=평생 고정 6개 / `weeklyLucky(birth,round)`=회차별 변동 / `quickPick(seed)`=뽑기 / `checkWinning(mine,win,bonus)`=6/45 등수(1등6·2등5+보너스·3등5·4등4·5등3) / `NUMBER_MEANING`(45) / `ballColor`.
- `daily.ts`: `dailyFortune(subjectKey, periodKey)`=종합점수(45~99)+분야별4(love/money/work/health)+행운요소(숫자3·색·아이템). `ZODIAC`(12)·`STAR`(12)·`zodiacOfYear(year)`·`starOfDate(m,d)`. **오늘·띠·별자리·월간·신년이 전부 이 함수 재활용**(periodKey만 다름: today=날짜 / week / year / year-month).
- `dream.ts`(v3): `DREAMS`(44종, 각 {luck·meaning·overview 문단[]·**situations 그룹별 케이스[]**(DreamCaseGroup{group, cases:DreamCase{label,luck,text}})·fields 분야별·psych·advice·aliases·related}). 핵심 14종은 situations 디럭스(돼지 5그룹 24케이스). `searchDreams(q)`=**멀티토큰 점수 검색**(keyword5/alias3/situation라벨2/overview1 + AND가산, `expandTokens`로 전역 SYNONYMS 유사어 확장)·`dreamsByCategory`·`interpretDream`=꿈+관련꿈+caseCount+행운번호6. 뷰 `DreamView.tsx`(강조검색+결과수·멀티워드안내, 상황별 그룹·분야별·심리·조언·관련꿈). 엔진수정→`npm run build -w @portal/engine` 먼저.
- `couple.ts`: (구) `compatibility(a,b)`=키 sort로 순서무관, 점수+제목+good/tip+행운수3 — 시드텍스트(현재 미사용, 타 화면 호환용 잔존).
- **궁합 v3(2026-06-28, "읽을거리·재미 가득")**: `coupleEngine.ts` v2에 대량 추가 — **coupleType**(점수+합/충 bond로 캐릭터 6종), **hashtags**(십성·bond·상보로 #태그), **narrative**(롱폼 3문단), **tenGodToMe/tenGodToPartner**(factors의 "상대에게"/"나에게" 십성 파싱→`TENGOD_ROLE`맵, 관계의 80%), **bondCodes**(자체 지지관계 테이블 `BR_YUKHAP/CHUNG/WONJIN/GWIMUN/HAE/SAMHAP`로 천간합(일간 index차5)·일지·띠 관계 판정+스토리), **loveStyles/treatTips**(`LOVE_STYLE`/`TREAT_BY_EL` 오행맵), **crisisSituation/Overcome**, **pastLife**(합충 테마), **intimacyScore/Text**(속궁합, 브랜드 안전선). ⚠️ App `routeFromHash`에 `.split("?")[0]` 추가(공유 딥링크 `#/couple?p=`가 home으로 빠지던 버그 수정). ## 프론트 연결 (web)
- 라우터(`App.tsx` 해시): `#/lotto #/today #/zodiac #/star #/dream #/couple #/wealth #/life #/taegil #/newyear #/monthly #/manse #/tarot`.
- 점수형 5종은 `FortuneView` 한 컴포넌트가 `mode`(today/zodiac/star/newyear/monthly)로 처리. 재물·평생·택일은 전용 뷰(`components/extra/{WealthView,LifeView,TaegilView}`).
- 날짜 키 유틸 `lib/dateKey.ts`: `todayKey/weekKey/yearKey/monthKey`(+ label). 엔진 순수 유지용(UI가 오늘 날짜 생성).
- 타일 카탈로그 `data/topics.ts`(순서=인기순, featured=로또). **새 콘텐츠 = topics.ts 한 줄 + 라우트 + 뷰**.
