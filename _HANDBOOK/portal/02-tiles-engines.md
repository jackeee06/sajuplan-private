# 운세 포털 — 13개 타일 상세 (무엇을 보여주나)

통합 운세 포털(unse.sajuplan.com)의 13개 콘텐츠 타일을 엔진별로 묶어 설명. 모두 **결정론적**(같은 입력=항상 같은 결과)이며 **재미·참고용**(완결적 AI 풀이 아님, 깊은 풀이는 상담 유도).

## 🍀 로또 — 오늘의 행운번호 (강조 타일)
- **평생 운명번호**: 생년월일+성별로 뽑은 6개 번호. 한 번 정해지면 안 바뀌는 "내 번호"(통계사이트가 복제 못 하는 시그니처).
- **행운의 뽑기**: 버튼 누를 때마다 새 6개(의식·재미).
- 각 숫자에 운세 한 줄 풀이(45개), 동행복권 색 공.
- ⚠️ **판매 아님** — 번호 추천·생성·당첨확인 도구만. "당첨 보장/예측" 금지, 19세·과몰입 면책. 실구매는 동행복권.

## 사주 점수형 (오늘·띠·별자리·월간·신년) — 같은 엔진(dailyFortune)
- **오늘의 운세**: 생년월일 → 오늘 종합운 + 분야별 4개(애정·금전·직장·건강) + 행운요소(숫자·색·아이템).
- **띠별 운세**: 생일에서 띠 자동 계산 → 오늘 운세(칩으로 직접 선택도 가능).
- **별자리 운세**: 생일에서 별자리 자동 계산 → 이번주 운세.
- **월간 운세**: 생년월일 → 이번 달 흐름.
- **신년운세**: 생년월일 → 올해 한 해 운세.
- → 모두 같은 점수+문장 구조. 점수는 긍정 편향(45~99), 문장은 점수대별 풀(높음/중간/낮음)에서 결정론적 선택.

## 🐷 꿈해몽 (v3 — 꿈 하나 = 긴 기사, 2026-06-28)
- 인기 꿈 **44종**. 꿈별 구성: **길흉 등급**(대길/길몽/중립/주의/흉몽) + 한 줄 요약 + **상세 해몽**(여러 문단) + ⭐**상황별 풀이**(색깔·마리수·내 행동·꿈속 상황별 다수 케이스, 각 길흉 표시 — 돼지=24케이스 5그룹 디럭스) + **분야별 영향**(재물·애정·건강·직장) + **심리 해석** + **행동 조언** + 관련 꿈(클릭 이동) + 행운번호 6.
- **검색 강화**: 최상단 강조 검색 + **멀티워드**("돼지 도망"·"검은 돼지" → 상황 라벨까지 매칭해 점수 랭킹) + **유사어**(별칭 + 전역 SYNONYMS: 구렁이→뱀·변→똥 등). 카테고리 브라우즈(전체/재물/길몽/애정/변화/주의).
- ✅ **44종 전부 디럭스 완료**(2026-06-28): 모든 꿈이 상황별 3~5그룹 × 케이스마다 3문장 + 전통 속설(folk) + 분야별 + 심리 + 조언. 글자수 2,100~3,700자. 결정론적. 당첨 보장/예측 아님(19세).

## 💞 궁합 (v3 — 읽을거리·재미 가득, 2026-06-28)
- **만세 엔진 `computeCompatibility(나, 상대)`**(두 명식 + 점수/레벨 + 합충 근거 + 신살 + 오행) 결합 = 경쟁사(점신·포스텔러·사주아이) 상위호환. 사람들이 가장 좋아하고 공유하는 주제라 "읽을거리·재미"에 집중.
- 결과 구성(19섹션): 종합 점수 + **겉궁합(띠)/속궁합(일주)** → ⭐**궁합 유형 캐릭터**(천생연분형/찰떡케미형/단짝연인형/애증밀당형/성장하는연인형/노력으로빛나는형) + **케미 해시태그**(#천생연분 #불꽃케미 등) → ⭐**롱폼 종합 서사**(3문단) → ⭐**일간 십성 관계 양방향**("상대는 당신에게 듬직한 사람" / "당신은 상대에게…" = 관계의 핵심 80%) → ⭐**인연 코드**(천간합·일지 육합/삼합/충/원진/귀문/해·띠 합충 각각 스토리 풀이) → 두 명식 미니 → **연애 스타일**(각자, 오행 기반) → **마음을 여는 법**(상대/나 각각) → ⭐**속궁합 케미**(점수+풀이, 브랜드 안전선) → 오행 상보 그래프 → 신살 케미 → 분야별 4 → 관계 타임라인 → ⭐**위기와 극복법**(상황+극복) → ⭐**전생 인연 스토리** → 좋은점/조심/갈등팁 → 행운 숫자 + 공유(링크복사 `#/couple?p=생일`) → 상담 CTA.
- 계산(간지·합충·오행·신살)은 **정확**, 점수·문장은 룰베이스 해석(과장 OK). 완결 분석 안 함 → 깊은 건 상담 CTA.
- **순서 무관**(A+B = B+A)·**결정론적**. "나"는 자동 채움, 상대만 생일 입력(상대 성별 내 반대 가정·시각 모름). ⚠️ 공유 딥링크는 `routeFromHash`가 `?` 쿼리 제거 후 매칭(안 하면 home으로 빠짐).
