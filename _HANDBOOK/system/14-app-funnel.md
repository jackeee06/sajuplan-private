# 앱 유입 깔때기 — 웹은 보되 상담은 앱에서 + 상담사 링크 공유 (2026-06-25)

## 한 줄로 답하면
**검색·카톡으로 들어온 사람이 상담사 정보는 웹에서 그대로 보지만, "전화·채팅 상담"을 누르는 순간 "앱에서 하세요 + 앱 받기"로 자연스럽게 유도한다. 검색 페널티 없이(콘텐츠는 가리지 않음) 앱 다운로드·앱 사용으로 모으는 방식이다. 더불어 상담사가 자기 상담실 링크를 카톡·SNS로 손쉽게 뿌릴 "내 상담실 링크 공유하기" 버튼도 생겼다.**

---

## 무슨 목표였나 (쉬운 말로)

웹을 검색·카톡에 노출(SEO)했더니 사람들이 웹으로 들어오기 시작했다. 그런데 사주플랜의 진짜 무대는 **앱**(전화·채팅 상담, 코인, 알림이 다 앱에서 매끄럽다). 그래서 **"웹은 최대한 안 쓰게 하고 앱으로 모으고 싶다"**는 게 목표였다.

단, 절대 조건이 하나 있었다 — **검색에서 불이익(페널티)을 받는 행동은 하면 안 된다.**

### 하면 안 되는 것 (검색 페널티)
- **클로킹** — 검색 로봇한테는 내용을 다 보여주고, 사람한테는 빈 화면/벽을 보여주는 것. 구글이 "속였다"고 보고 검색에서 빼버린다.
- **전면 설치 팝업** — 모바일에서 화면을 통째로 가리는 "앱 받으세요" 팝업. 구글이 순위를 깎는다.

→ 옛날에 만들어 둔 "전체화면 앱 전용 차단" 기능을 켜는 건 이 둘을 동시에 어기는 거라 **쓰지 않기로** 했다.

---

## 어떻게 해결했나

### 핵심: "내용"과 "행동"을 분리한다
- **내용**(상담사 사진·소개·후기 등 공개 프로필) → 웹에서도 **그대로 다 보여준다**. 검색 로봇이 보는 것과 사람이 보는 게 똑같으니 **클로킹 아님 = 페널티 없음.**
- **행동**(전화·채팅 상담 시작) → 누르는 순간 상담 화면 대신 **"앱에서 상담할 수 있어요" 안내 + 앱 받기 버튼**을 띄운다.
- 결과: **"보긴 웹에서, 상담은 앱에서"**. 검색·카톡 노출은 그대로 유지하면서, 진짜 행동은 앱으로 빨려 들어간다.

### 어디서 막히나
- 상담사 목록·상세 어디서든 **전화상담 / 채팅상담** 버튼을 누르면 → 앱 유도 시트가 뜬다 (안드/아이폰 자동 구분해 알맞은 스토어 버튼).
- 단, **이미 앱 안에서** 쓰는 사람은 그대로 상담이 진행된다(앱은 막지 않음).

### 상담사 "내 상담실 링크 공유하기" 버튼 (신규)
- 상담사 마이페이지 **"상담사 관리" 바로 위**에 가로로 긴 핑크 버튼이 생겼다.
- 누르면 공유창이 열리고 — **"링크 복사하기"가 맨 위·제일 크게** 있다.
- 복사한 링크를 카톡·블로그·인스타에 붙여넣으면, 받는 사람 화면엔 상담사 **사진·이름·한줄소개가 담긴 카드**로 뜬다(검색 노출용으로 만든 그 카드).
- 카드 설명엔 **한줄소개 · 전문분야 · 스타일**이 들어간다 → 상담사가 프로필을 많이 채울수록 카드가 풍성해진다.

> 왜 "링크 복사"를 1순위로? 카카오톡 공유 버튼(SDK)은 **받는 사람을 카카오가 멋대로 골라두거나** 안드로이드에서 실패하는 일이 잦다(보낸 사람이 엉뚱한 채팅방으로 가는 사고). **링크 복사 → 원하는 채팅방에 직접 붙여넣기**가 가장 확실하다.

## 이건 정상인가요? 에러인가요?

| 상황 | 판단 |
|---|---|
| 웹에서 전화/채팅 버튼 → "앱에서 상담하기" 시트가 뜸 | ✅ 정상 (앱 유도) |
| 웹에서 상담사 프로필·소개·후기는 그대로 다 보임 | ✅ 정상 (콘텐츠는 가리지 않음 = 페널티 회피) |
| 앱 안에서는 전화/채팅이 그대로 진행됨 | ✅ 정상 (앱은 게이트 안 함) |
| 상담사 공유 버튼 → "링크 복사하기"가 맨 위에 큼 | ✅ 정상 (의도된 1순위) |
| 카톡 버튼으로 보냈더니 엉뚱한 사람에게 감 | ⚠️ 카카오 공유창이 받는 사람을 미리 골라둔 것 — 우리 버그 아님. **링크 복사**로 안내 |
| 링크 복사 카드가 옛 정보로 보임 | ⚠️ 카카오가 미리보기를 잠시 캐시함 — 새 채팅방에 공유하거나 시간 지나면 갱신 |
| 한줄소개가 빈 상담사의 카드가 허전함 | ⚠️ 정상 — 상담사가 프로필(한줄소개·분야·스타일)을 채우면 풍성해짐 |

## 점검은 어떻게 했나

- `e2e/tests/117-app-funnel-and-share.spec.ts` — **4건 전부 통과.**
  - 웹에서 전화상담 클릭 → 프로필은 보이고 앱 유도 시트가 뜸(콘텐츠 안 가림 확인), 채팅상담도 동일, E2E 자동화는 게이트 예외(기존 상담 흐름 보호), 상담사 "내 상담실 링크 공유하기" → 공유창 + 링크복사 1순위·안내문구 노출.
- SEO 카드(서버 OG)도 같이 점검 — `114-seo-rendering` 6/6 통과.

## 아직 안 한 것 (의도적 보류)
- **상시 앱설치 배너** — 여러 화면 레이아웃 깨질 위험 + 상담 누르는 순간이 더 효과적이라 보류.
- **코인 충전 앱 잠금** — 웹 충전도 앱에서 쓸 수 있는 잔액(매출)이라, 막을지는 사장님 확인 후.
- **링크 클릭 → 앱 자동 열림(딥링크)** — 이건 앱 재빌드+스토어 심사가 필요한 별도 작업. 설계서 `_APP_DEEPLINK_SPEC.md`. (지금 깔때기는 앱 손 안 대고 웹만으로 동작)
