# 사주플랜 앱 (WebView) 의 특수 동작

## 한 줄로 답하면
**사주플랜 앱은 RN WebView 셸 (앱 안에 사주플랜 웹 사이트). 일반 모바일 웹과 다른 특이점 몇 가지 있음 — 외부 URL 차단·캐시 갱신 지연 등.**

## 주요 특이점

### 웹 개방 — 일반 브라우저 허용 (2026-06-21 사장님 결정) ★현재 상태
- 사주플랜은 원래 **앱 전용**(브라우저 차단)이었으나, 상담사 요청으로 **일반 웹사이트처럼 브라우저(PC·모바일)에서도 정상 노출**하도록 **개방**했다. 이제 `sajuplan.com` 을 브라우저로 열면 "앱에서 이용해주세요" 화면 없이 사이트가 그대로 보인다.
- **웹·앱은 같은 서버·DB·계정** — 앱은 그 웹을 띄우는 WebView 셸이라, 웹에서 가입/결제/이용한 것이 전부 **계정에 쌓여 앱과 그대로 호환**된다.
  - 웹에서 가입 → 앱에서 **같은 아이디·비번 로그인 정상** (소셜가입은 소셜버튼으로 로그인).
  - 웹에서 결제 → 코인이 **계정에 충전**되어 앱에서 그대로 사용. (코인·내역·쿠폰·상담내역 모두 계정 단위라 웹·앱 공유)
- **기기에 묶이는 건 FCM 푸시뿐** — 브라우저는 푸시 미지원. 상담사가 실시간 상담요청을 받으려면 앱을 켜두는 게 좋다(카톡 알림톡은 브라우저와 무관하게 도달).
- 구현: `web/user/src/components/WebAppGate.tsx` 의 `WEB_OPEN = true` (게이트 항상 통과). **되돌리려면(다시 앱 전용으로 막기) `WEB_OPEN=false` 후 재배포** → 아래 옛 게이트 로직이 부활.
- (옛 게이트 2026-06-12~06-21, 코드 보존) 통과 예외: 앱 WebView(`isNativeApp`)·`navigator.webdriver`(E2E)·`localStorage.__allow_web__='1'`(운영자 점검). PC=QR 2개, 모바일=스토어 버튼으로 설치 유도했었음.

### 외부 URL 차단
- 앱 WebView 안에서 외부 사이트 클릭하면 새 탭 안 열림
- "openExternalUrl" 같은 별도 처리 필요 (사주플랜 시스템이 알아서)

### 캐시 갱신 지연
- 앱이 옛 화면 캐시하고 있을 수 있음
- 새 정책 배포 후 일부 사용자에게 옛 화면 보이는 경우 가능
- 강제 새로고침 또는 시간 지나면 갱신

### 알림 → 앱 자동 이동 (푸시/FCM 이동 방식 — 안드로이드·iOS 모두 정상)
- 카카오 알림톡 클릭 시 앱 이동 = **푸시/FCM 이동 방식**. 안드로이드·iOS 둘 다 동일 기능으로 등록·구현됨 (정상). 앱이 꺼져 있어도 켜지고 **정확한 페이지로 이동**됨.
- BizM 설정·백엔드·서버·사주플랜 코드 = 변경 0 (정상). 안드로이드가 정상이므로 BizM/서버 문제 아님. **BizM·서버 변경 불필요.**
- 일부 아이폰 에러 제보는 iOS 기능 자체는 등록돼 있으므로 **그 단말의 앱 미설치/구버전 등 환경 가능성** (단정 금지).

## 이런 상황을 보셨나요?

### "회원이 옛 화면 보고 있대요"

→ 캐시 가능성 1순위. 강제 새로고침 안내. 그래도 안 되면 시스템 사고.

### "외부 링크 클릭이 안 돼요"

→ WebView 한계. 사주플랜 화면에서 외부 사이트는 별도 처리 필요. 운영자가 등록한 외부 링크 (배너, 공지 등) 가 안 되면 시스템 점검.

### "알림톡 클릭하니 카톡 브라우저에서 사주플랜 사이트가 열려요"

→ 카카오 알림톡 클릭 시 앱 이동은 푸시/FCM 이동 방식이며 안드로이드·iOS 모두 정상 등록. 앱이 꺼져 있어도 켜지고 정확한 페이지로 이동됨. BizM·서버 변경 불필요.

## 이건 정상인가요? 에러인가요?

| 상황 | 답변 |
|---|---|
| 앱 안에서 사주플랜 동작 | ✅ 정상 |
| 브라우저(PC/모바일)로 접속 → 사이트 정상 노출 | ✅ 정상 (2026-06-21 웹 개방, `WEB_OPEN=true`) |
| 웹에서 가입/결제 → 앱에서 같은 계정으로 이어짐 | ✅ 정상 (웹·앱 같은 서버·DB·계정. 코인·내역 공유) |
| 다시 앱 전용으로 막고 싶음 | `WEB_OPEN=false` 후 재배포 (옛 게이트 부활) |
| 외부 사이트 클릭 → 시스템 브라우저 열림 | ✅ 정상 (sajuplan 자동 처리) |
| 옛 캐시로 옛 화면 노출 | ⚠️ 일시적 |
| FCM 푸시 알림 **탭** → 해당 화면으로 이동 | ✅ 정상 (navigateWebView) |
| 카톡 알림톡 **버튼** 클릭 → 앱 열리나 홈으로 | ⚠️ 딥링크 미연결(앱 재빌드 대기, 2026-06-21 아이폰 실측). 옛 iOS 크래시는 해결됨. → [alert/07-ios-alimtalk-crash](alert/07-ios-alimtalk-crash) · `_BACKLOG_카톡버튼_화면이동.md` |
| 회원이 앱 못 열어요 | ❌ APK 다운로드 / 설치 안내 |
