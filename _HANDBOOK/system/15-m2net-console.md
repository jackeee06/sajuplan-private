# 엠투넷 콘솔 — 이제 Claude가 대신 본다 (사장님 직접 접속 불필요)

## 한 줄로 답하면

**엠투넷(외부 실시간 과금 시스템)의 관리자 화면을 이제 Claude가 직접 열어서 확인한다. 사장님이 passcall.co.kr 에 직접 로그인할 일이 없다.**

## 엠투넷이 뭐길래 중요한가

엠투넷(m2net / PassCall)은 **통화·채팅을 실제로 연결하고, 실시간으로 과금하는 외부 회사**다. 사주플랜의 **매출·정산·차감의 진짜 원천**이 여기다. 상담사 수익금도 "엠투넷 실과금 × 수익률"로 계산된다. 그래서 돈 문제·과금 이상·상담 연결 사고를 파악하려면 엠투넷 화면의 실제 숫자와 대조하는 게 결정적이었다.

지금까지는 **사장님이 엠투넷에 직접 들어가 화면을 캡쳐**해주셔야 했다. 이제는 **Claude가 필요할 때 알아서 들어가 확인**한다.

## 엠투넷 콘솔에 있는 화면 (문자발송관리 제외 — 우리가 쓰는 것만)

|---|---|---|
| **통화상세내역** | 전화상담 1건씩 (상담사ID·통화시간(초)·시작/종료·선불여부) | 전화 매출·정산의 실측 원장 |

| **상담연결실패이력** | 연결 실패 건 | 상담 연결 사고 원인 |
| **VIP관리 / 블랙리스트 / 가상계좌입금내역** | 특수 회원·입금 | 운영 예외 확인 |

## 이제 이렇게 됩니다

- **평소:** 사장님은 엠투넷에 **직접 들어갈 필요가 없습니다.**
- **돈·과금·상담연결·정산·충전·차감을 분석할 때:** "엠투넷 봐줘"라고 말씀하지 않으셔도, **Claude가 필요하다고 판단하면 알아서 엠투넷에 들어가 우리 데이터와 비교**하며 문제를 풉니다.
- **콕 집어 보고 싶으실 때:** "엠투넷 통화상세 오늘 것 봐줘", "이 회원 엠투넷 충전이력 확인해줘"처럼 말씀하시면 그 화면을 열어 판독해 드립니다.

## 안전장치

- **읽기 전용:** Claude가 쓰는 도구는 **화면을 보기만** 합니다. 코인 지급·상태 변경 같은 **돈을 바꾸는 버튼은 일부러 안 넣었습니다.** 실수로도 돈을 못 건드립니다.
- **돈을 실제로 바꿔야 할 때:** 정식 API 경로로, **사장님 확인을 받고서만** 합니다.
- **자격증명 보안:** 아이디·비번은 개발 PC의 잠긴 파일(`.env.local`)에만 있고 **git·외부로 나가지 않습니다.**
