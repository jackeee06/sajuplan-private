# SEO 서버렌더 — 검색·카톡 노출 (2026-06-25)

## 한 줄로 답하면
**사주플랜은 앱(SPA)이라 원래 구글·네이버·카톡 같은 "기계(봇)"가 우리 사이트를 열면 빈 로딩 화면만 봤다. 이제 봇이 올 때만 서버가 "제목·소개·사진이 담긴 진짜 화면"을 그려서 주도록 만들어서, 검색에 잡히고 카톡 공유 시 카드가 뜬다. 사람은 예전처럼 빠른 앱 화면 그대로 본다.**

---

## 무슨 문제였나 (쉬운 말로)

사주플랜 사용자 사이트는 **앱처럼 동작하는 웹(SPA)** 이다. 사람이 열면 잠깐 로딩 후 화면이 그려진다 — 사람 눈엔 문제없다.

그런데 **검색엔진(구글·네이버)이나 카카오톡** 같은 "기계"는 사람처럼 화면이 그려지길 기다려주지 않는다. 그 기계들이 우리 주소를 열면 **글자 하나 없는 빈 로딩 화면**만 받아갔다. 게다가 모든 페이지의 제목이 똑같이 `사주플랜` 이었다.

결과:
- **네이버 검색에 안 잡힘** — 네이버 봇은 화면 그려지는 걸 거의 못 기다림.
- **카톡 공유가 허전함** — 상담사 링크를 카톡에 보내도 사진·이름 카드가 안 뜸.
- 구글도 페이지 구분이 안 돼 상담사별로 검색에 안 뜸.

웹을 일반 사이트처럼 개방(2026-06-21)했는데, 정작 검색·카톡이라는 **가장 큰 유입 통로가 막혀 있던** 셈이다.

---

## 어떻게 해결했나

### 핵심: "봇한테만" 진짜 화면을 그려서 준다 (dynamic rendering)
- 사이트에 **기계(봇)** 가 들어오면 → 서버가 그 페이지의 **제목·소개·사진·후기수**가 담긴 **완성된 HTML**을 만들어 돌려준다.
- **사람**이 들어오면 → 예전처럼 **빠른 앱 화면(SPA)** 을 그대로 준다. (바뀐 것 없음)
- 누가 봇이고 누가 사람인지는 접속 정보(브라우저 종류)로 자동 구분한다. 구글이 공식적으로 권장하는 방식이며, **봇과 사람에게 같은 내용**을 주므로 페널티 없음.

### 대상 페이지
- 메인, 상담사 전체 목록, **상담사 상세**(가장 중요), 공지 상세, 이벤트 상세.

### 같이 켜진 것
- **검색 노출** — 구글·네이버가 상담사 프로필 내용을 읽어가 검색 결과에 뜰 수 있다.
- **카톡 공유 카드** — 상담사 링크를 카톡에 보내면 사진·이름·소개가 **카드 모양**으로 뜬다.
- **sitemap(사이트 지도)** — `sajuplan.com/sitemap.xml` 에 상담사 전체 + 공개 페이지 목록을 자동으로 만들어, 검색엔진이 빠짐없이 찾아가게 한다.
- **robots.txt** — 검색엔진에게 "공개 페이지는 와도 되고, 마이페이지·관리자·내부파일은 오지 마"라고 알려준다.

### 일부러 안 넣은 것 — 별점
- 상담사 별점은 **현재 화면에 안 보이는 정책**(정착도 낮아 0.0 노출이 신뢰도 해침)이라, 검색 결과에도 별점을 **일부러 넣지 않았다**. 화면엔 없는데 검색엔만 별점이 뜨면 구글이 "속임수"로 보고 불이익을 준다. 나중에 별점 화면이 부활하면 그때 검색에도 추가한다.

## 남은 일 — 검색엔진 등록 (사장님 5분 작업)

기술은 다 깔렸지만, **검색에 실제로 뜨려면** 네이버·구글에 "이 사이트 내 거예요" 한 번 등록해야 한다. 로그인이 필요해 대신 못 눌러드린다.
- 네이버 서치어드바이저 + 구글 서치콘솔에서 소유권 확인 → sitemap 제출.
- 소유권 확인용 파일(`naverXXX.html` / `googleXXX.html`)만 받아서 주시면 **즉시 사이트에 올려드린다**(코드 변경 없음).
- 단계별 클릭 순서: 저장소 `_SEO_SETUP_GUIDE.md`.

> 등록해도 검색에 바로 안 뜬다 — 구글 며칠, 네이버 1~2주가 보통. sitemap 제출로 가속만 가능.

## 이건 정상인가요? 에러인가요?

| 상황 | 판단 |
|---|---|
| 카톡에 상담사 링크 공유 → 사진·이름 카드 뜸 | ✅ 정상 (OG 카드) |
| 사람이 사이트 열면 예전 앱 화면 그대로 | ✅ 정상 (사람은 SPA, 안 바뀜) |
| `sajuplan.com/sitemap.xml` 열면 주소 목록 XML | ✅ 정상 |
| 검색에 아직 안 뜸 (등록 직후) | ⚠️ 정상 — 색인에 며칠~2주 걸림 |
| 네이버 앱 안에서 사이트 열었는데 멈춤/이상 | ❌ 비정상 — 봇 판정 오인 가능, 보고 (네이버 봇은 `yeti`만 잡게 해둠) |
| 상담사 정보 수정했는데 검색·카톡 카드가 옛날 정보 | ⚠️ 캐시(서버 10분 / sitemap 30분) — 잠시 후 갱신 |

## 점검은 어떻게 했나

- `e2e/tests/114-seo-rendering.spec.ts` — **6건 전부 통과.**
  - 봇으로 열면 상담사 상세가 제목·소개·OG·사이트지도 정보가 담긴 완성 화면, 사람으로 열면 예전 앱 화면(회귀 없음), 카톡 봇은 카드 정보, sitemap·robots 정상까지 자동 클릭 확인.
- 실제 `sajuplan.com` 에서 봇/사람/카톡 각각 접속해 분기 정상 확인.
