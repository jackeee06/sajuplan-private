# 사주플랜 도메인 (실제 운영 vs 테스트)

## 한 줄로 답하면
**실제 운영은 sajuplan.com (옛 sajumoon.co.kr 도 같이 살아있음). PROD 단일 운영이고, 옛 테스트 서버(sajumoon.kr)는 2026-05-29 폐기됨.**

## 도메인 매핑

| 환경 | 사용자 도메인 | API 도메인 | 용도 |
|---|---|---|---|
| **실제 운영** | sajuplan.com | api.sajuplan.com | 회원 실 사용 |
| **옛 브랜드** | sajumoon.co.kr | api.sajumoon.co.kr | 옛 도메인 호환 (같은 서비스) |
| ~~테스트 (폐기)~~ | ~~sajumoon.kr~~ | ~~api.sajumoon.kr~~ | ~~2026-05-29 폐기. PROD 단일 운영~~ |

## 이런 상황을 보셨나요?

### "회원이 sajumoon.co.kr 에서 접속해요"

→ 옛 브랜드 도메인. 사주플랜 (sajuplan.com) 과 같은 서비스. 정상.

### "새 기능 테스트는 어디서?"

→ 별도 테스트 서버 없음 (폐기됨). 현재는 PROD(sajuplan.com) 단일 운영 + E2E 자동 테스트(Playwright)로 검증 후 배포.

### "sajumoon.kr 는 왜 안 떠요?"

→ ✅ 정상. 2026-05-29 폐기 결정된 옛 테스트 서버(172.235.211.75)라 더 이상 운영 안 함. 무응답이 정상이고 복구 대상 아님.

## 이건 정상인가요? 에러인가요?

| 상황 | 답변 |
|---|---|
| sajuplan.com 접속 → 정상 서비스 | ✅ 정상 |
| sajumoon.co.kr 접속 → 같은 서비스 | ✅ 정상 (옛 도메인 호환) |
| sajumoon.kr 무응답 | ✅ 정상 (폐기된 옛 테스트 서버) |
| sajuplan.com 에 회원 못 가입 | ❌ critical 사고 |

## 서버 시간 = 한국시간(KST)

서버·DB·앱 모두 **한국시간(KST, +0900)** 으로 돕니다. 그래서 "오늘 상담", "이번달 정산", "출석 하루 1회" 같은 **날짜 경계가 한국 자정 기준** 으로 정확히 끊깁니다.

> **2026-06-17 교정 이력**: 원래 서버가 실수로 **중국시간(+0800)** 으로 돌고 있었습니다. 저장된 시각 자체는 안전했지만(국제표준 UTC 로 보관), `오늘`·`이번달` 같은 경계 계산이 한국보다 **1시간 일찍** 넘어가서 — 한국 자정~새벽 1시 사이의 상담·출석·정산이 전날·전월로 샐 위험이 있었습니다. 이날 OS·DB·앱을 모두 한국시간으로 맞춰 교정 완료. 돈 무결성 검증 PASS.

| 상황 | 답변 |
|---|---|
| `date` 결과가 `KST +0900` | ✅ 정상 (한국시간) |
| `date` 결과가 `CST +0800` (중국) | ❌ 사고. 1시간 시차 → 날짜 경계 어긋남. 즉시 교정 |
