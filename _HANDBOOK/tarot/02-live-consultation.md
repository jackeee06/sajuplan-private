# 전화타로 라이브 상담 — 운영 가이드

## 어떻게 들어가나요 — 앱 홈 "타로상담" 버튼 (2026-06-26)

앱 홈 상단(통계카드 아래)에 **[무료 만세력 | 타로상담]** 2분할 버튼이 있습니다. 오른쪽 **타로상담**이 진입구:

- **평소**: 누르면 "전화 타로가 뭔지" 알려주는 **안내 페이지**(`/tarot-intro`)로 이동(이미지+설명+"타로 상담사 보러가기").
- **타로 전화상담 진행 중**: 같은 버튼이 **핑크로 변하고 "타로 상담 입장"** 으로 바뀜 → 누르면 **카드 보드로 바로 입장**. 코드 입력 없음.

> 왜 홈 버튼? 상담사는 늘 쓰는 버튼이라 잘 찾지만, **고객은 전화로 타로를 시작하고 앱에 돌아오면 당황해서 평소 보던 이 버튼을 누릅니다.** 그래서 이 익숙한 버튼이 진행 중이면 곧장 상담 화면으로 연결되도록 설계했습니다. 상담사·고객 모두 자기 토큰만으로 누르면 서버가 "둘은 지금 통화 중"이라는 매칭으로 같은 방에 붙여줍니다.

## 상담 흐름 전체 (상담사 기준)

### 1. 방 생성 (상담 시작 전)
- `tarotroom.sajuplan.com?role=counselor&session=통화ID&mName=고객이름` 접속
- (또는 앱 재빌드 전 임시) 직접 URL 입력
- **"타로 방 만들기"** 버튼 → 방코드 4자리 발급

### 2. 고객 초대
- 고객에게 `tarotroom.sajuplan.com?role=member&session=통화ID&cName=상담사이름` URL 공유
- (앱 연동 후) 앱이 URL 자동 생성 → 코드 입력 불필요

### 3. 배열 선택
- 상담사가 스프레드 6종 중 선택 → 고객 화면에도 동시 표시
- 쓰리카드는 포지션 세트 선택 (과거·현재·미래 / 상황·행동·결과 등)
- 역방향 카드 사용 여부 체크 (기본 ON)

### 4. 셔플 (의식)
- 상담사가 "카드 섞기" → 양쪽 화면에 카드 섞기 애니메이션
- 상담사가 전화로: **"카드에 마음을 집중하며 질문을 떠올려 보세요. 준비되시면 말씀해주세요."**
- 고객이 "됐어요" → 상담사가 **"고객 준비 완료 — 멈추기"** 버튼 탭

### 5. 카드 뽑기
- 고객 화면에 78장 격자 펼쳐짐
- 고객이 직접 탭 → 뽑을 때마다 숫자 팡! 플래시
- 상담사 화면: 진행 상황 실시간 표시

### 6. 카드 공개 (핵심!)
- 상담사가 한 장씩 탭 → 양쪽 동시 공개 (고객 화면 ●●● 대기 → 공개)
- 상담사 화면에 표시되는 정보:
  - 포지션 (과거·현재·미래)
  - 카드 이름 + 정/역 + 원소
  - 📖 상세 설명 2~3문장
  - ❤️💼💰🏥 분야별 한 줄씩
  - 💬 상담 질문 2개 제안

### 7. 마무리
- 상담사가 "다음 리딩" → 리셋 후 새 스프레드로

## 화면 역할 차이 요약

| 단계 | 상담사 | 고객 |
|---|---|---|
| 배열 선택 | 선택 클릭 가능 | 미선택 타일 흐림 = 상담사가 고른 배열 미리보기 |
| 셔플 | "멈추기" 버튼 | "준비되면 상담사에게 말씀해 주세요" |
| 뽑기 | 진행 상황 모니터링 | **78장 격자에서 직접 탭** |
| 공개 | **한 장씩 탭으로 공개** + 상세 의미 패널 | 카드 이름만 (상담사가 펼치는 중) |
| 완료 | 상세 패널 + "다음 리딩" | 카드 이름 (상담사가 전화로 해설 중) |

### 고객 화면 — 상단 상태배너 (지금 뭘 해야 하나)

손님은 라이브 상담 내내 대부분 "구경 + 대기"이고, 실제로 손을 쓰는 건 **카드 뽑기 한 단계뿐**이다. 그래서 헷갈리지 않도록 **화면 맨 위에 가로 한 줄 배너**를 둬, 단계마다 "기다리세요 / 지금 고르세요"를 못 놓치게 알려준다. 모든 대기·행동요청 안내가 **[반짝 핑크 비콘][안내 + 사유] 한 줄** 패턴으로 통일(저압식·모바일 세로공간 절약, 포인트는 "반짝이는 비콘").

- **대기(회색 바탕 + 핑크 핑 비콘)**: "잠시만 기다려 주세요" + 사유(상담사가 배열 고르는 중 / 카드 섞는 중 / 펼치는 중 / 해설 중). 비콘의 퍼지는 파동이 "살아있다, 기다려라" 신호.
- **내 차례(연핑크 바탕 + 핑크 글자)**: 카드 뽑기 단계에서만 — 👆 비콘 + "카드를 골라 주세요" + "원하는 카드 N장 · 0/N 선택". 큰 블록 없이 색으로만 은은하게 구분.
- 로비의 배열 타일은 고객에겐 **흐린 미리보기**("상담사가 고를 배열 미리보기" 캡션) — 못 만지는 행동 대상 아님을 명시.

> 개선 이력(2026-06-26): ① 안내가 맨 아래 흐린 가짜버튼에 묻혀 "배열을 선택합니다"라는 못 하는 행동을 안내 → 상단으로. ② 글자·점이 작아 "기다리라" 핵심을 못 찾음 → 반짝 핑 비콘을 포인트로. ③ 큰 히어로가 모바일 세로공간을 너무 먹어 → **아이콘+글자 가로 한 줄**로 컴팩트화. ④ **상담사·솔로 화면의 안내도 전부** 같은 비콘 한 줄로 통일(기존 큰 세로 스택·노란 강조박스 제거). 반짝 비콘 = "지금 할 일" 이정표.

### 카드 공개 연출 — 한 장씩 펼칠 때 "과한 액션"

상담사가 카드를 한 장 탭해 공개하는 순간을 이벤트로 만든다: **3D 플립 + 카드 팝(확 커졌다 안착) + 금빛 글로우 링 + ✨ 스파클이 사방으로 비산.** 상담사·고객·솔로 모든 화면에서 동일하게 터지고, 픽 시 숫자 플래시와 합쳐져 더 풍성하다. (재접속으로 이미 공개된 카드엔 안 터짐.)
