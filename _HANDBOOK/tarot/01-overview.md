### 리딩 흐름
1. **로비** — 상담사: 배열 선택 + 셔플 / 고객: 같은 배열 화면 보기(버튼 잠김)
2. **셔플** — 카드 섞기 애니메이션. 상담사가 안내 후 "멈추기" / 고객: "준비되면 말씀해주세요"
3. **픽(뽑기)** — 고객이 격자 78장에서 직접 탭. 뽑을 때마다 숫자 팡! 플래시
4. **공개** — 상담사가 한 장씩 탭해 공개(양쪽 동시). 고객엔 "상담사가 펼치고 있습니다" ●●● 표시
5. **완료** — 상담사: 카드별 상세 의미 패널(설명+분야별+상담 질문 제안) / 고객: 카드 이름만 간결하게

### 상담사 전용 카드 정보 패널
공개된 카드마다:
- 📖 **카드 설명** — 2~3문장 상세 의미
- 분야별 의미 — ❤️ 연애 / 💼 직업 / 💰 금전 / 🏥 건강 각 한 줄
- 💬 **상담 질문 제안** — 2개 (고객에게 바로 던질 수 있는 질문)

> 카드 1장당 상담사가 읽을 내용 2~3분 분량 → 자연스럽게 상담 시간·매출 연장.

## 상담 프로세스 안전선 (절대 규칙)

1. **앱은 카드+키워드+한 줄까지만** — 완결적 AI 해석 금지(상담사 가치 보존)
2. **마케팅 타로 = 맛보기** — 깊은 풀이는 상담사에게 유도
3. **돈 흐름과 완전 분리** — 타로보드는 무료 시각 보조, m2net 과금 무관
4. **노골적 CTA 금지** — 결과 화면에 큰 "상담사에게 가라" 버튼 없음 (은은한 푸터만)
