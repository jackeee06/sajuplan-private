# 모집인 되기 · 회원 추천 귀속 (자가신청 · 추천코드 · 사후입력) (✅ 운영 — 2026-06-18)

> **✅ 구현·배포 완료 (2026-06-18).** 모집인 자가신청→승인, 추천코드 입력 UX, 사후 입력 복구까지 운영 중.
> 승인 통보 알림톡(`promoter_approved`)만 BizM 검수 통과 후 자동 발송(DB 본문 준비 완료).

## 한 줄로 답하면
**모집인은 ① 관리자 수기 등록 또는 ② 본인이 직접 신청→관리자 승인으로 등록된다. 회원은 가입할 때 추천코드(전화 뒷4자리)를 넣으면 그 모집인에게 연결되며, 깜빡했어도 가입 후 7일 안에 마이페이지에서 한 번 넣어 복구할 수 있다.**

---

## 1. 모집인이 되는 2가지 경로

### (1) 관리자 수기 등록
- 사이드바 → 회원현황 → **모집인 관리** (`/promoters`) → [모집인 등록]
- 이름·전화·계좌·코드 입력. 코드 비우면 자동생성(전화 뒷4자리).

### (2) 자가 신청 → 관리자 승인  ⭐ 2026-06-18 추가
1. 신청자가 `sajuplan.com/promoter` 접속 → 휴대폰 번호 입력 → **OTP 인증**
2. 미등록 번호면 **에러 대신 신청 폼**(이름·은행·계좌·예금주) 노출
   - **회원이기도 하면 이름이 자동으로 채워짐**(prefill)
3. 신청 시 `status = 'pending'`(승인 대기)으로 등록
4. 관리자가 **모집인 관리 → 상세**에서 **[승인]** 또는 **[반려]**
   - 승인 → `status = 'active'`, 활동 시작
   - 승인 시 **통보 알림톡**(`promoter_approved`, 변수 `#{이름}`) 자동 발송(BizM 검수 후)
5. **코드 자동생성**: 전화 뒷4자리. 이미 쓰는 코드면 숫자 앞에 **'A' 접두**(예: `0572` 사용 중 → `A0572`)

> 상태 뱃지: **승인 대기(주황)** / **활성(초록)** / **반려(회색)**. 목록 상단 필터로 대기 건만 모아볼 수 있다.

---

## 2. 회원이 모집인에게 연결되는 법 (추천 귀속)

- **코드 = 모집인 전화번호 뒷 4자리** (시끄러운 술집에서도 외우기 쉽게)
- 입력 경로 2가지 — 결과는 동일:
  1. **QR/링크 자동채움**(prefill) — 링크를 연 그 브라우저 안에서 바로 가입할 때
  2. **코드 직접 입력** — 가입 화면에서 4자리 타이핑
- **한 회원 = 모집인 1명**, 가입 시 확정. **자기추천 차단**(본인 전화번호와 일치 시 거부)

---

## 3. ⚠️ "링크만 타면 자동 적용"의 현실 (꼭 알 것)

사장님과 2026-06-18 정리한 **중요한 제약**:

| 상황 | 추천 자동 연결 |
|---|---|
| 링크를 연 **그 브라우저에서 곧바로 가입** | ✅ 자동(prefill) |
| 링크는 브라우저로 보고 → **앱을 새로 깔아 앱에서 가입** | ❌ **안 됨** (저장소 분리로 코드 유실) |

- 사주플랜은 **앱 전용 서비스**다([[WebAppGate]], 일반 브라우저 가입은 차단 — 예외 `/s/`·`/promoter`). 그래서 **신규 회원은 무조건 "브라우저 → 앱 설치 → 앱에서 가입"** 경로를 거치고, 이때 브라우저에 저장된 코드가 **앱으로 전달되지 않는다.**
- "클릭→설치→코드 자동주입"(Deferred Deep Link, Install Referrer/Branch)은 **앱 네이티브 수정·재배포가 필요**한데, **앱 재심사·재배포는 안 하기로** 함(사업 방해).
- **결론: 신규 회원은 추천코드를 손으로 한 번 입력하는 것이 기본**이다. 코드가 4자리라 부담은 작다. 누락은 아래 사후 입력으로 구제한다.

> 현장 안내 멘트 권장: *"이 링크 눌러서 나온 화면에서 바로 가입해줘"* 또는 *"가입할 때 추천코드 `0572` 꼭 넣어줘"*.

---

## 4. 추천코드 입력 UX (2026-06-18 보강)

### 가입 화면 — 접이식 코드칸
- 평소엔 **"추천코드가 있으신가요?"** 작은 링크만 보임 → **일반 가입자는 전혀 방해 안 받음**
- 추천 받은 사람만 눌러서 4자리 입력. QR/링크로 들어오면 자동으로 펼쳐지고 채워짐

### 사후 입력 복구 — 마이페이지  ⭐ 핵심 안전망
- 가입할 때 코드를 못 넣었어도, **가입 후 7일 이내에 마이페이지에서 한 번** 추천코드를 넣으면 연결됨
- 앱 신규설치 경유로 누락된 코드를 살리는 **유일한 안전망**
- 조건: 아직 미귀속 + 가입 후 7일 이내 + 유효 코드 + 자기추천 아님 (1회만)
- 과거 사용분 소급 없음(입력 시점 이후 상담부터 적립) → 어뷰징 차단

> 모집인 복구 멘트: *"가입했어? 코드 깜빡했으면 마이페이지에서 `0572` 넣어줘"*

---

## 5. 공유 문구 정책

카톡 공유 카드·랜딩 문구는 **"이 링크로 가입하면 자동 적용"** 같은 표현을 쓰지 않는다(신규엔 사실이 아니라 코드 누락 유발). → **"가입할 때 추천코드 0572 입력"** 으로 명확히 안내한다.
