# 모집인(서포터즈) 회원모집 보상 제도 (✅ 운영 — 2026-06-18 구현·배포)

> **✅ 현재 상태 (2026-06-18): 구현·배포 완료** (API + 사용자/관리자 프론트 + DB 4테이블).
> 단 **실시간 적립 알림톡은 BizM 템플릿 승인 후 활성**(setting `promoter.alimtalk_enabled`, 기본 false).
> 설계서: `PLAN/promoter-referral.md`.

## 한 줄로 답하면
**일반인(대학생 알바 등)이 길거리·술집에서 비가입자에게 사주플랜을 홍보→가입시키고, 그 회원이 실제로 쓴 유료 사용액의 3%를 회사가 모집인에게 보상하는 마케팅 제도. 2026-06-18 운영 시작.**

## 호칭

- **시스템·관리자·계약 용어**: "모집인"
- **대외 브랜드**: "사주플랜 서포터즈"
- (속어 "삐끼"는 대외 사용 금지 / "파트너"는 상담사 등급과 충돌하므로 금지)

## 기존 "추천"과 무엇이 다른가 (헷갈리지 말 것)

| 구분 | 상담사 추천수익금 (기존·운영 중) | 모집인 보상 (신규·운영) |
|---|---|---|
| 추천인 | 상담사 | 일반인(앱 안 깔아도 됨) |
| 부담 주체 | 피추천자(제로섬) | **회사 100% 부담** |
| 원장 | `earning_balance`(수익금 원장) | **별도 원장**(코인·수익금 안 건드림) |
| 비율/기간 | 1% / 3개월 | 3% / 3개월 (관리자 변경 가능) |
| 정산 | 정산 로직 연동 | **수동 정산** |

> ⚠️ 둘은 **완전히 다른 제도**다. 모집인 보상은 회원 코인·상담사 수익금 원장(돈 불변식)을 **절대 건드리지 않는다.**

## 보상 정책

- **기준**: 피모집 회원의 **실사용 유료분(상담 소비 중 유료코인 차감분, `consultation.amt_pro`)의 3%**
- **기간**: 회원 가입 후 **3개월**
- **발생 조건**: 회원이 실제로 유료 사용한 만큼만 적립 (가입 머릿수로는 0원 — 어뷰징 차단)
- **상한**: 없음
- **변경**: 비율(3%)·기간(3개월)은 관리자에서 변경 가능. 단 **가입 시점 값이 회원별로 스냅샷 고정**(이후 정책 변경은 신규 가입자부터)
- **부담**: 사주플랜(순수 마케팅 비용)

## 모집인 등록 (관리자 수기 + 자가신청)

- 별도 존재 — **앱 설치 불필요**, 회원·상담사가 아니어도 됨
- 필요 정보: 이름 · 전화번호 · 입금계좌 · 코드
- **등록 2경로**: ① 관리자 수기 등록 ② **본인 자가신청 → 관리자 승인**(`sajuplan.com/promoter` OTP 인증 → 신청폼 → 승인/반려). 상세: [자가신청·추천귀속](promoter/03-signup-attribution)
- **코드**: 전화번호 뒷4자리(술집에서도 외우기 쉽게). 중복 시 **숫자 앞에 'A' 자동 접두**(예: `0572`→`A0572`) → 코드는 항상 유니크
- 회원이기도 하면 자동 연결(전화번호 일치) — [모집인 듀얼 시나리오](#모집인이-회원으로도-가입하는-경우)

## 귀속 (회원 ↔ 모집인 연결)

- 입력 2가지 경로 — 결과는 동일:
  1. **QR/링크**: 가입 화면에 코드 자동입력(prefill)
  2. **코드 직접 입력**: 술집 등 QR 못 찍는 상황 (전화 뒷4자리 타이핑)
- **한 회원 = 모집인 1명**, 가입 시 확정, **영구 변경 불가**
- 이름 확인 절차 없음(회원은 모집인 이름을 모름. 코드가 유니크하므로 불필요)

> ⚠️ **"링크만 타면 자동 적용"은 신규 회원에겐 사실상 안 된다.** 사주플랜은 앱 전용이라 신규는 "브라우저→앱설치→앱가입" 경로를 거치며 이때 코드가 유실된다(앱 재배포 안 함 → 딥링크 불가). **추천코드 손입력이 기본**이고, 깜빡하면 **가입 후 7일 내 마이페이지 사후입력**으로 복구한다. 전체 동작·UX: [자가신청·추천귀속](promoter/03-signup-attribution)

## 모집인이 회원으로도 가입하는 경우

문제 없음. 모집인과 회원은 별개 층이라 회원가입은 정상 진행되고 원장도 섞이지 않는다.
- 전화번호 일치 → 자동으로 한 사람으로 연결
- ⚠️ **자기추천 금지**: 회원가입 시 자기 코드 입력은 차단(자기충전 어뷰징 방지)
- 다른 모집인 코드로 가입은 정상 허용
