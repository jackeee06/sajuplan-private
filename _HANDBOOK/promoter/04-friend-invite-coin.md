# 회원 친구초대 코인 보상 (코인형 모집인 — 카톡 쿠폰 바이럴) ✅ 운영

> **✅ 현재 상태 (2026-06-20): 구현·배포·검증 완료** (백엔드 + 앱 화면 + 공개 페이지 + 쿠폰 이미지/OG).
> 통제 테스트로 "친구 유료상담 → 초대자 코인 +3% → 화면 표시"까지 실제 확인 + 돈 무결성 PASS.

## 한 줄로 답하면

**기존 회원이 카톡으로 "신규가입 만원 무료코인 쿠폰"을 친구에게 선물 → 친구가 추천코드로 가입 후 실제로 충전해서 쓰면, 그 유료 사용분의 3%를 초대한 회원에게 무료코인으로 적립해주는 바이럴 마케팅. "모집인" 시스템을 재활용한 코인형 보상.**

## 현금형(서포터즈) vs 코인형(회원 친구초대) — 완전히 다른 트랙

같은 `promoter` 인프라를 쓰지만 **별개 제도**다. `promoter.reward_type` 으로 갈린다.

| 구분 | 현금형 (서포터즈) | 코인형 (회원 친구초대) |
|---|---|---|
| 참여자 | 일반인(앱 불필요, 모바일웹) | **앱 회원** |
| 보상 | **현금** (통장, 수동 정산·원천징수) | **무료코인** (free_balance, 출석코인과 동일 성격) |
| 관리 | 관리자 "모집인 관리"에서 **별도 수동 관리** | **관리 불필요** — 무료코인 흐름 그대로 |
| 가입 경로 | 모바일웹 `/promoter` (OTP) | 앱 마이페이지 → 친구 초대 |
| reward_type | `cash` | `coin` |

> **코인형은 "모집인"이 아니라 "무료코인 한 종류"로 본다.** 출석코인을 따로 관리하지 않듯, 회원 친구초대 코인도 별도 관리화면이 없다. 회원 코인내역/포인트 내역에 "친구초대 보상"으로 찍힌다.

## 보상 정책 (확정)

| 항목 | 값 |
|---|---|
| 보상 대상 | 초대한 **회원**(코인) — 친구(피초대자)는 가입 시 만원 자동(기존 register_point) |
| 보상 기준 | 친구의 **유료 사용분(충전해서 쓴 금액)의 3%** — 공짜코인 사용분 제외 |
| 보상 기간 | 친구 1명당 **가입 후 3개월** (화면엔 작게 표기, 혜택을 전면에) |
| 보상 형태 | **코인**(free_balance 즉시 적립) — 현금 없음 |
| 환불 시 | **코인 회수 안 함**(회사 부담). 적립 원장만 voided, 코인은 유지 |
| 다단계 | **없음**(직접 추천만). 친구의 친구는 무관 |
| 상한 | **없음**(친구 수·금액 제한 없음). 3%×실사용이라 자기제한적 |
| 부담 주체 | 사주플랜(회사 마케팅 비용). 상담사 수익금·정산 **무침범** |

## 회원이 보는 화면 (앱)

**마이 → 마이페이지 → "친구 초대"** (`/mypage/invite`)
- **가로형 쿠폰 미리보기**: 사주플랜 로고 + "만원 무료코인 쿠폰" + **추천코드(큰 글씨)**. (폰 화면에 맞춘 가로 모양)
- **내 추천코드 + [코드 복사]**: 전화 뒷4자리. 친구가 가입 시 꼭 입력해야 적용.
- **"친구에게 꼭 알려주세요"**(코드 강조 안내 — 카톡 버튼 위에 배치): ① 가입 시 코드 입력 ② 앱 새로 깔면 코드 자동 안 붙음→꼭 불러주기 ③ 깜빡하면 7일 내 사후입력
- **[카카오톡으로 쿠폰 선물하기]**: 코드 박힌 쿠폰 카드 발송 (제목에도 코드)
- **내 초대 현황**: 초대한 친구 수 / 받은 코인 누적 / 적립 타임라인("OO 님 N코인 사용 → +M코인")

## 직원·가족·지인 (보상 없이 호의로 뿌리기)

**공개 쿠폰 페이지** `sajuplan.com/event` (로그인·앱 불필요, 앱 게이트 예외)
- 누구나 열어 [카카오톡으로 쿠폰 공유하기] → 코드 없는 쿠폰. 추적·보상 없음(순수 홍보).
- 친구는 가입하면 만원 자동(누구나 받는 보상).
- ※ 보상받는 외부 영업은 현금형 모집인(`/promoter`)으로.

## 카톡에서 쿠폰 이미지

- **앱 안 "카톡 선물하기" 버튼** → 코드 박힌 **정사각형** 쿠폰 카드 (카카오 카드는 정사각 크롭이라 정사각형이 딱 맞음)
- **링크 복붙(OG)** → `/event`·`/s/{코드}` 도 카카오 봇에 쿠폰 OG 카드 노출 (nginx 봇 분기)
- 코드는 **이미지 안에 큰 숫자**로 박힘(서버 즉석 합성, 회원마다 다름)

## 코드 규칙

- 코드 = **전화번호 뒷 4자리** (중복 시 앞에 'A'). 전화 없는 테스트 계정은 회원ID로 폴백(3자리 등 — 실사용자는 항상 4자리).
- 코드 생성은 **회원이 친구초대 화면을 열 때**(lazy). 안 쓰는 회원은 행이 안 생겨 관리자 화면이 깨끗.
- 친구 귀속: 한 회원 = 추천인 1명 영구. 자기추천 차단(전화 일치). 가입 시 확정 + **7일 내 사후입력** 구제.

## 운영자가 적립을 보는 곳

- **회원 본인**: 친구 초대 → "내 초대 현황" + 코인 내역
- **관리자**: 그 회원의 **코인 내역 / 포인트 관리** 화면에 "친구초대 보상"으로 표시 (출석코인과 동일). **별도 관리화면 없음**(코인형은 자동지급이라 정산 불필요).
