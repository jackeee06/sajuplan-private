# 모집인 적립 · 정산 · 알림톡 (✅ 운영 — 2026-06-18)

> **✅ 구현·배포 완료.** 실시간 적립 알림톡만 BizM 템플릿 승인 후 활성(`setting promoter.alimtalk_enabled`). 설계서 `PLAN/promoter-referral.md`.

## 한 줄로 답하면
**피모집 회원이 유료 상담을 쓸 때마다 그 유료분의 3%가 모집인 "기대수익"으로 적립되고(실시간 알림톡 통보 — 게이트), 관리자가 수동으로 원천징수 떼고 통장 송금한다. 2026-06-18 운영.**

## 적립

- **시점**: 회원의 상담 종료(m2net push로 `consultation` 생성) 직후
- **금액**: `floor(consultation.amt_pro × 3%)` — 유료 사용분만(무료코인 사용분 `amt_free` 제외)
- **조건**: 회원에게 모집인 귀속이 있고, 가입 후 3개월 이내, 유료 사용분 > 0
- **멱등**: 상담 1건당 1회만 적립
- **원장 분리**: 회사 비용 원장에만 기록. 회원 코인·상담사 수익금(point/earning) **무침범** → 돈 무결성(`_verify_money_integrity.py`) 영향 없음

## 환불 시

- 해당 상담이 환불되어 유료 사용분이 줄면 → **대응 적립분 차감(void)**
- 이미 모집인에게 지급된 보상이면 → 다음 정산에서 상계(이월)

## 알림톡 2종 (모집인은 앱 미설치 → 카톡이 유일 도달)

| 알림톡 | 시점 | 템플릿코드 | 상태 |
|---|---|---|---|
| **승인 통보** | 자가신청 승인 시 | `promoter_approved` (변수 `#{이름}`) | ✅ DB 본문 준비완료 / ⏳ BizM 검수 통과 시 자동발송 |
| **실시간 적립** | 회원 유료사용 적립 시 | (신규 등록 필요) | ⏳ 게이트 off (`setting promoter.alimtalk_enabled`) |

> 승인 통보 상세: [자가신청·추천귀속](promoter/03-signup-attribution).

## 실시간 적립 알림톡

모집인은 앱을 안 깔았으므로 **알림톡(카톡)이 유일한 도달 경로** → 푸시 아님.

- **발송**: 적립 1건마다 (멱등 1회) 모집인 전화번호로
- **문구 예**: "홍** 님이 30,000원을 사용해 +900원이 적립되었습니다. 누적 기대수익 45,000원"
- **회원 마스킹 필수**(`홍**`) — 사주/타로 사용은 민감 개인정보
- **누적 기대수익 동봉** — 숫자가 쌓이는 체감이 동기부여 핵심
- **환불로 차감(void) 시엔 발송 안 함**(혼란·김 빠짐 방지) — 대시보드·관리자만 반영
- BizM 신규 템플릿 등록·검수 필요. 비용 건당 ~7원(폭증 시 일일 요약으로 전환 여지)

## 모집인 대시보드 (앱 불필요)

- **로그인**: 랜딩(`sajuplan.com/s`)에서 휴대폰 번호 + SMS 인증번호(OTP)
- **첫 화면**: ① **총 기대수익 크게 강조** ② 그 아래 **시간순 적립 타임라인**("○월○일 홍** 30,000원 사용 → +900원 적립") ③ 모집 인원 수 · 내 코드 · 정산 완료액
- 회원은 무조건 마스킹(`홍**`). 사용금액 숫자는 노출

## 정산 (수동)

- 관리자가 모집인별 미정산 보상 합을 확인 → 통장 송금 → [지급완료] 마킹 (선지급/월정산의 "지급완료 마킹" 패턴 재사용)
- **원천징수 뗀다**: 정산 시점에 모집인에게 주민번호 요청 → **안 주면 미지급**(no 주민번호 = no payout)
  - 원천징수율(기타소득 8.8% vs 사업소득 3.3%)은 정산 시작 전 세무 기준 확정
- 앱 없는 모집인에게 지급 통보 알림톡

## 빌드 단계 (전부 ✅ 완료 — 2026-06-18)

1. ✅ **코어 적립**: DB + 모집인 등록 + 가입 귀속 + 상담 종료 적립(+환불 차감)
2. ✅ **대시보드 + 자가신청·승인**: OTP 로그인 + 기대수익/타임라인 + QR/링크 + 자가신청→승인(+승인 알림톡)
3. ✅ **정산**: 관리자 정산 + 원천징수/주민번호 + 지급완료 마킹
4. ✅ **다듬기**: 추천코드 입력 UX(접이식·사후입력 복구) — ⏳ 실시간 적립 알림톡만 BizM 등록 대기
