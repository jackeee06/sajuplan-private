# 통합 알림함 (앱 안 종 모양 — 모든 알림 한 곳)

## 한 줄로 답하면
**회원·상담사에게 가는 모든 알림(푸시·인앱·카톡)이 앱 안 종 모양🔔 한 곳에 쌓입니다. 안 읽은 게 있으면 종 모양에 빨간 숫자 뱃지가 뜨고 살짝 까딱여요. 각 알림에 "어떤 경로로 왔는지"(📲푸시/💬카톡) 뱃지가 붙습니다.**

## ⭐ 2026-06-20 개편 — "휘발성" 해결
전엔 정작 자주 오는 알림(채팅요청·문의·후기·등급 등)을 **푸시·카톡으로만 쏘고 종모양엔 안 남겼습니다.** 그래서 폰 알림이 사라지면 "무슨 알림이 왔었지?" 확인할 곳이 없었어요. 이제 **이런 이벤트가 발생하면 종모양 알림함에 한 줄로 기록**되어, 폰 알림을 지워도 앱에서 다시 볼 수 있습니다.

- **한 사건 = 한 줄.** 같은 알림이 푸시+카톡 둘 다 나가도 종모양엔 한 줄, 대신 줄에 `📲푸시` `💬카톡` 뱃지가 붙어 "이게 카톡으로도 왔구나"가 보임.
- **카톡 내용도 종모양에서 확인.** 카카오톡을 못 봤어도 같은 내용이 종모양에 남아 있음.
- **안 읽음 종모양 뱃지 + 까딱(bounce).** 안 읽은 개수만큼 빨간 숫자, 읽으면 사라짐. 회원·상담사 헤더 어디서든(홈·마이페이지·상담사목록·단골·상담사신청) 동일.
- **과거 소급은 안 됨.** 개편 이전에 이미 나간 알림은 종모양에 없고, 개편 이후 발생분부터 쌓입니다.

### 🔒 보안 — 종모양에 절대 안 들어오는 것
**인증번호 · 임시비밀번호 · 운영자(사장님)용 운영 알림**은 종모양 알림함에 기록하지 않습니다. (폰을 잠깐 빌려준 사람이 인증번호·임시비번을 다시 보는 사고를 원천 차단 — 전화번호 매칭/필터가 아니라 "기록 자체를 안 함")

## 인앱(종모양) vs 알림톡 차이

## 인앱 vs 알림톡 차이

| 항목 | 인앱 | 알림톡 |
|---|---|---|
| 도달 | 사주플랜 앱 진입 후 | 즉시 (카톡) |
| 영구성 | 영구 (직접 삭제까지) | 카톡 30일 정도 |
| 차단 가능 | 사용자 불가 | 폰 차단 가능 |
| 채팅 중 | 발생 OK | 화이트리스트 외 차단 |

→ 알림톡 못 받아도 인앱은 살아있음 (정보 손실 없음).

## 이런 상황을 보셨나요?

### 회원이 "알림톡 안 왔어요" 라고 클레임

→ 인앱 (마이페이지 → 알림) 에 있는지 확인 권장. 같은 정보 받았을 가능성.

### "안 읽은 알림이 너무 많아요"

→ 인앱은 영구 보존이라 누적. 회원이 일괄 읽음 처리 또는 삭제 가능.

### "알림 클릭하니 빈 페이지로 가요"

→ deep link 어긋남. 옛 알림의 링크 페이지가 사라졌을 가능성 (예: 삭제된 게시글).

## 이건 정상인가요? 에러인가요?

| 상황 | 답변 |
|---|---|
| 회원 답변 받음 → 인앱 알림 + 알림톡 동시 | ✅ 정상 |
| 알림 클릭 → 해당 페이지 이동 | ✅ 정상 |
| 알림 읽음 처리 → 종 모양 빨간 숫자 뱃지 줄어듦/사라짐 | ✅ 정상 |
| 채팅 중 → 알림톡은 차단, 인앱(종모양)은 기록됨 | ✅ 정상 (정책) |
| 알림 줄에 `📲푸시`만 있고 `💬카톡` 없음 | ✅ 정상 (그 이벤트는 카톡 미발송이거나 수신자 폰 없음) |
| 개편(2026-06-20) 이전 알림이 종모양에 없음 | ✅ 정상 (소급 기록 안 함) |
| 인증번호·임시비번이 종모양에 보임 | ❌ **사고**(설계상 불가). 즉시 점검 |
| 인앱(종모양)에도 정보 안 옴 | ❌ **사고**. 알림 시스템 점검 |

## 운영자가 확인하는 위치

| 확인 항목 | 메뉴 위치 |
|---|---|
| 회원 인앱 알림 (대신 조회) | 사이드바 → 회원현황 → 고객 리스트 → 상세 → 알림 탭 |

## 알림 화면 구성 (2026-06-11 개편)

"폰 아이콘엔 배지 2가 떴는데 앱을 열면 아무것도 없네?" 하던 혼란을 풀기 위해 **3단**으로 개편했어요.

### ① 새 알림 "마중" 배너 (홈 상단)
홈에 들어오면 **안 읽은 알림이 있을 때** 상단에 보라 그라데이션 배너 **"새 알림 N개가 도착했어요 ✨"** 가 스르륵 떠요 → 탭하면 알림함으로 바로 이동.
- 안 읽은 알림이 0이면 안 뜸 / X로 닫으면 그 세션 동안만 숨김
- 폰 배지(OS 푸시)와 앱 안 알림(인앱)을 이어주는 "여기 있어요" 안내 역할

### ② 알림함 (카드형 리스트)
각 알림이 흰 카드 + **종류 아이콘·색**으로 한눈에 구분돼요:
- 💬 채팅요청 · 📞 전화요청 · ❓ 새 문의 · 💡 문의답변 · ⭐ 새 후기 · 🎉 등급승급 · 💰 정산 · 💸 선지급 · 🎁 쿠폰 · 🚨 신고 · ⏱️ 채팅취소
- 📢 전체공지(보라) · 👤 상담사(청록) · 👥 회원(파랑) — 관리자가 보낸 공지/알림
- 각 줄에 **채널 뱃지**(`📲푸시` / `💬카톡`)가 붙어 어떤 경로로 왔는지 표시
- 안 읽은 건 또렷 + **빨간 점**, 읽은 건 흐림 + "읽음"

### 종모양 빨간 뱃지 (안 읽음 표시)
헤더 종모양🔔 위에 **안 읽은 알림 개수**가 빨간 숫자 뱃지로 뜨고, 있으면 살짝 까딱(bounce)여요. 99개 넘으면 `99+`. 알림을 읽거나 "모두 읽음" 하면 줄어들고, 0이 되면 사라집니다. (60초마다 + 앱 복귀 시 자동 갱신)

### ③ 알림 상세 (탭하면)
알림을 탭하면 **바로 링크로 튀지 않고** 상세 페이지에서 **제목·본문 전체를 먼저** 보여줘요. 이동 주소가 있으면 하단에 **[바로가기]** 버튼.

### 클릭하면 일어나는 일
1. 안 읽음 → **읽음 처리** (빨간 점 사라지고 마중배너 숫자도 줄어듦)
2. **알림 상세로 이동** (목록의 알림 내용을 그대로 넘겨 즉시 표시 — 재조회 없음)
3. 상세에서 **[바로가기]** → 해당 페이지로 (앱 안 화면이면 매끄럽게 이동 / 외부 링크면 외부 브라우저로)

> 데이터 출처는 그대로 `notification_log` 테이블. 2026-06-20 개편으로 **이벤트성 알림도 여기에 한 줄씩 기록**되어 종모양이 "모든 알림 한 곳"이 됨.

## 어떤 알림이 종모양에 기록되나 (2026-06-20)

| 알림 | 받는 사람 | 같이 나가는 채널 |
|---|---|---|
| 채팅 상담요청 | 상담사 | 📲푸시 + 💬카톡 |
| 전화 상담요청 | 상담사 | 📲푸시 + 💬카톡 |
| 새 문의(Q&A) 도착 | 상담사 | 📲푸시 + 💬카톡 |
| 문의 답변 등록 | 회원 | 💬카톡 |
| 내 문의 신고됨 | 회원 | 📲푸시 |
| 새 후기 도착 | 상담사 | 📲푸시 + 💬카톡 |
| 등급 승급 | 상담사 | 📲푸시 + 💬카톡 |
| 상담 부재 안내 | 상담사 | 💬카톡 |
| 채팅 자동취소 | 회원 | 💬카톡 |
| 정산 완료 | 상담사 | 💬카톡 |
| 선지급 접수/입금/반려 | 상담사 | 💬카톡 |
| 쿠폰 발급 | 회원 | 💬카톡 |

> ❌ 제외(보안/운영): 인증번호 · 임시비밀번호 · 운영자 운영알림(OpsAlert) · 가상계좌 입금안내(계좌번호 PII).
> 관리자가 "알림 보내기"로 직접 보낸 공지(전체공지/회원/상담사)도 당연히 종모양에 기록됨.
