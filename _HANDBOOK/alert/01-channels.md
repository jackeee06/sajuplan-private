# 사주플랜은 어떤 알림을 어떻게 보내나요?

## 한 줄로 답하면
**사용자에게 알리는 방법은 세 부류 — ① 보내는 알림(인앱·푸시·알림톡) ② 보여주는 콘텐츠(배너·팝업) ③ 시스템 자동 알림(코드가 자동). "보내는 알림"이 핵심.**

## 전체 그림 (이 표만 알면 안 헷갈림)

### ① 보내는 알림 — 이벤트 때 1회 발송 → "보낸 이력"이 남음
| 채널 | 도달 | 앱 꺼져도? | 어디서 보냄 |
|---|---|---|---|
| **인앱 알림** | 앱 안 종모양🔔 목록 | ❌ 앱 켜야 | 알림 → **알림 보내기** (🔔인앱 체크) |
| **푸시(FCM)** | 폰 OS 알림 | ✅ | 알림 → **알림 보내기** (📲푸시 체크) |
| **알림톡(BizM)** | 카카오톡 | ✅ | 알림 → **알림톡 발송(수동)** (승인 템플릿) |

> **인앱·푸시는 "알림 보내기" 한 화면**에서 제목·본문 쓰고 **[🔔인앱][📲푸시] 체크로 채널 선택** 발송(2026-06-19). **푸시를 켜면 인앱은 자동으로 함께 발송**됩니다("푸시만"은 없음) — 폰 알림을 지워도 종모양에서 내용을 다시 볼 수 있게 하기 위함.
> **알림톡은 BizM 승인 템플릿만** 보낼 수 있어 자유 작성 불가 → 그래서 별도 화면.

> **★ 2026-06-20 통합 알림함:** 시스템이 자동으로 쏘는 이벤트 알림(채팅요청·문의·후기·등급·정산·선지급·쿠폰 등)도 **푸시·알림톡과 함께 종모양🔔 알림함에 한 줄로 기록**됩니다. 한 줄에 `📲푸시`/`💬카톡` 뱃지로 어느 채널로 갔는지 표시 → 폰 알림/카톡을 못 봐도 종모양에서 모두 확인. 안 읽은 게 있으면 종모양에 빨간 숫자 뱃지. (단, **인증번호·임시비번·운영자 알림은 보안상 종모양 기록 제외**) 상세 = [통합 알림함](alert/06-inapp-notifications).

### ② 보여주는 콘텐츠 — 등록해두면 노출 기간 동안 계속 보임 ("발송"이 아니라 게시)
| 종류 | 위치 | 어디서 관리 |
|---|---|---|
| **상단 배너** | 홈 상단 슬라이드 | **콘텐츠/노출 → 상단 배너** |
| **팝업 모달** | 홈 진입 시 "오늘 하루 안 봄" | **콘텐츠/노출 → 팝업 모달** |

> 배너·팝업은 알림과 **용도가 다름**(보내는 게 아니라 게시)이라 **알림 그룹이 아닌 "콘텐츠/노출" 그룹**에 둔다.

### ③ 🤖 시스템 자동 알림 — 관리자 관리 X (코드가 상황 따라 자동 표시)
**점검 안내 배너 · 단골 접속중 배너 · 상담사 새 채팅요청 배너 · 채팅 5분 알림 · 출석/등급 토스트** 등.
관리자가 만들거나 끄는 **화면이 없습니다**(시스템 자동). **추가·수정이 필요하면 개발팀에 문의** — 관리자가 못 찾는 게 정상.

> **이벤트별 채널 한눈에 (단일출처):** 어떤 알림이 어느 채널로 나가는지는 **알림 가이드** 페이지(사이드바 → 알림 → 알림 가이드)에서 표로 확인.
> 그 표의 **데이터 진실원천(SSOT)은 `_HANDBOOK/alert/_matrix.json`** — 바이블·AI·관리자 페이지가 같은 뿌리를 읽으므로 드리프트가 생기지 않는다. (2026-06-18 단일출처화)

### 알림톡 + FCM 둘 다 보내는 이벤트 (탭 시 화면 직행)
- 채팅 상담요청 / 전화 상담요청 / 문의(Q&A) 도착 / 등급 승급 / **새 후기**(2026-06-18 FCM 추가) → 모두 **상담사** 대상.
- 푸시를 탭하면 앱이 `event_url` 로 해당 화면 자동 이동(딥링크·앱재빌드 불필요, FCM 이동코드 기구현). 카톡 알림톡 버튼은 앱 열기(홈)만 한다.

> ⏸️ **"알림톡 나가는 모든 알림을 FCM도 보내자" 확대안은 보류(park, 2026-06-18).** 나중 재검토. 현재는 위 5종만 둘 다. 정산·선지급·쿠폰 등은 알림톡만.

## 정책

### 회원 / 상담사 입장
- 정보성·거래성 알림만 (가입, 결제, 채팅 요청, 정산 등)
- 마케팅성 알림 X (카카오 정책 + 사장님 결정)

### 채팅 중 차단
- 회원·상담사가 채팅 진행 중일 때 다른 알림톡 자동 차단
- 화이트리스트: `chat_request_to_counselor` (다른 회원의 새 채팅 요청) 만 통과

→ [채팅 도중 다른 알림 안 가는 이유](chat/04-alert-block)

## 이런 상황을 보셨나요?

### 회원이 "왜 답변 알림톡 안 왔어요?" 라고 클레임

→ 가능 원인:
1. 회원이 채팅 중이었음 (자동 차단)
2. 회원 폰이 070 차단
3. BizM 발송 사고

→ 답변: "마이페이지에 인앱 알림은 도착했습니다 (정보 손실 없음). 채팅 중이셨을 가능성이 큽니다."

### "사장님이 일일 요약 알림 못 받았어요"

→ 사장님이 그 시각에 채팅 중이었거나, 폰 차단. 일일 요약은 다음 날 자동 재발송 X (한 번 발송).

### "마케팅 알림톡 보내고 싶어요"

→ 카카오 정책상 거부될 가능성 큼. 정보성으로 우회 가능 (예: 이벤트 안내).

## 이건 정상인가요? 에러인가요?

| 상황 | 답변 |
|---|---|
| 회원 답변 받음 → 알림톡 + 인앱 동시 | ✅ 정상 |
| 회원 채팅 중 → 알림톡 차단, 인앱은 발생 | ✅ 정상 (정책) |
| 알림톡 발송 후 인앱에는 안 옴 | ❌ **사고**. 인앱 알림 시스템 점검 |
| 마케팅 알림톡 시도 → BizM 거부 | ✅ 정상 (정책) |
| 사장님이 매일 일일 요약 못 받음 | ⚠️ 차단 또는 cron 사고. 점검 |

## 운영자가 확인하는 위치

| 확인 항목 | 메뉴 위치 |
|---|---|
| 알림 보내기 (인앱·푸시 채널 선택) | 사이드바 → 알림 → 알림 보내기 |
| 알림톡 발송(수동) + 이력 | 사이드바 → 알림 → 알림톡 발송(수동) |
| 알림톡 템플릿 | 사이드바 → 알림 → 알림톡 템플릿 |
| 알림톡 이력 (자동·수동 전체 발송기록) | 사이드바 → 알림 → 알림톡 이력 |
| 알림 전체 가이드 (전체 카탈로그) | 사이드바 → 알림 → 알림 전체 가이드 |
| 배너·팝업 (보여주는 콘텐츠) | 사이드바 → 콘텐츠/노출 |
