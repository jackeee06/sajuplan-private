# 사주플랜페이 자동충전

## 한 줄로 답하면
**회원이 카드를 한 번 등록하면, 코인 잔액이 부족할 때 사주플랜이 자동으로 결제해 코인을 충전합니다. 상담 중 갑자기 코인이 부족해 끊기는 상황을 막기 위한 기능입니다.**

---

## 왜 자동충전을 만들었나요?

1. **상담 중 끊김 방지** — 전화·채팅 상담 중 코인이 소진되면 상담이 강제 종료됩니다. 이때 회원이 즉시 충전하기 어렵고, 상담사도 갑작스럽게 상담이 끊깁니다. 자동충전이 있으면 이 문제가 없어집니다.
2. **회원 편의** — 매번 충전 페이지를 방문하는 번거로움을 없애줍니다.
3. **플랫폼 매출 안정화** — 코인 부족으로 상담을 못 하는 경우를 줄여 플랫폼 전체 매출이 늘어납니다.

---

## 동작 흐름

```
회원이 카드 등록 (사주플랜페이)
  ↓
상담 진행 중 코인 잔액이 임계값 이하 감지
  ↓
사주플랜이 등록된 카드로 자동 결제 (AG9 빌링)
  ↓
결제 성공 → 코인 즉시 적립
  ↓
회원에게 알림톡 발송 (자동충전 완료 안내)
```

---

## 카드 등록 흐름

```
회원 → 마이페이지 → 충전 → 자동충전 카드 등록
  ↓
AG9에서 빌링키 발급 (카드번호 직접 저장 X, 토큰만 저장)
  ↓
DB에 빌링키 저장 (payment_autopay 테이블)
```

> ⚠️ 카드번호는 사주플랜 서버에 저장되지 않습니다. AG9(PG사)에서 발급한 빌링키만 저장합니다. 보안 원칙.

---

## 경우의 수별 설명

### Q. "자동충전 등록 현황을 보려면?"
→ 매출현황 → 결제 내역 → `자동충전` 탭 필터

### Q. "자동충전이 실패하면?"
→ 결제 실패 알림톡이 회원에게 발송됩니다.
→ 실패 이력은 결제 내역에서 확인 가능

### Q. "회원이 카드를 삭제하면?"
→ 자동충전 비활성화. 다음 상담 전에 회원이 직접 재등록해야 합니다.

### Q. "자동충전 금액은 어떻게 결정되나요?"
→ 충전금액 설정에 등록된 상품 중 특정 금액으로 자동 설정됩니다.

---

## 현재 운영 상태

코드 완비, 실 사용 초기 단계. 매출 대부분은 아직 수동 카드결제·가상계좌이고 자동충전 비중은 작습니다(자동충전 관련 이슈는 매출현황 → 결제 내역에서 확인).

> 📌 **2026-06-26 정리된 사고**: 카드는 등록했지만 "자동실행"을 안 켠 회원에게 m2net 이 통화 중 자동충전을 했는데, 예전엔 우리 시스템이 이를 "위조 의심"으로 막아 **돈은 빠졌는데 코인을 못 주는** 일이 있었습니다(강원구·진유비). 이제는 **본인 등록 카드면 코인을 정상 지급**하도록 고쳤습니다. 또 결제를 취소(환불)하면 **취소 통지가 충전으로 잘못 처리돼 코인이 또 들어가던** 문제도 막았습니다. 환불 절차는 [환불 정책](payment/04-refund) 참고.

> 🟡 **2026-06-28 조사 — 우리BC 카드 거절 (미해결, 카드사/PG 확인 중)**: 홍루연 회원이 사주플랜페이로 11만원 자동결제를 시도하자 우리카드(우리BC)가 `"가맹점 조치 후 승인 가능"`으로 거절했습니다(응답코드 `req_result=07`). **우리 시스템은 정상**입니다 — 같은 자동결제로 **다른 카드(진유비·강원구)는 성공**했고, 우리 요청은 우리카드까지 정상 도달해 우리카드가 직접 거절 문자를 보냈습니다. 즉 **우리 잘못이 아니라 카드사 측 거절**입니다. 여기서 "가맹점"은 카드소유자가 아니라 **결제대행 가맹점(KCP/엠투넷)** 을 뜻하므로, 회원이나 카드사 소비자센터가 아니라 **엠투넷/AG9에 사유를 문의**해야 합니다. (브랜드 무관 — 홍루연·강원구 둘 다 마스터카드인데 결과가 갈림.) 참고로 자동충전 실사용은 매우 적습니다(90일 성공 2건).

## 이건 정상인가요? 에러인가요?

| 상황 | 판단 |
|------|------|
| 상담 중 자동 결제 후 코인 적립 | ✅ 정상 |
| 카드 한도 초과로 자동충전 실패 | ✅ 정상 (회원에게 알림) |
| 빌링키 없이 자동충전 시도 | ❌ 버그 — 즉시 확인 |
| 자동충전 후 중복 코인 적립 | ❌ 이중충전 버그 — 즉시 확인 |
| 카드 등록했지만 자동실행 OFF인데 통화 중 자동충전됨 | ✅ 정상 (코인 지급, 운영자 경보) |
| 결제 취소(환불) 후 코인이 또 적립됨 | ❌ 이중지급 버그 — 이제 막혀 있음. 발생 시 즉시 확인 |
| 결제 취소 통지(CANCEL_PAY) 경보 수신 | ✅ 정상 (취소는 적립 안 함 — 안내 경보) |
| 특정 카드(예: 우리BC) 자동결제가 `req_result=07`로 거절 | ⚠️ 카드사 거절 — 우리 잘못 아님. 다른 카드는 정상. **엠투넷/AG9에 사유 문의** (회원·우리카드 소비자센터 아님) |
