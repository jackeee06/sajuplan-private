# 무료 만세력 — 일일운세 (오늘·주간·월간·평생운세)

## 한 줄로 답하면
**`manse.sajuplan.com` 상단 [만세력·일일운세·궁합] 탭 중 "일일운세". 띠 또는 생년월일시를 넣으면 오늘의 운세를 풍성하게(별점·점수·분야별·행운·로또·띠궁합까지) 보여주고, 기간을 [오늘·이번주·이번달·평생]으로 바꿔 볼 수 있다. 한 번 넣은 정보는 만세력·궁합과 세션 동안 공유된다. (2026-06-25 신설)**

## 무엇인가요 — 왜 만들었나요?
일일운세는 만세력 사이트의 **마케팅·바이럴 무기**입니다.

- "오늘의 운세"는 "만세력"보다 일반인에게 훨씬 친숙·대중적 → 검색·공유 유입이 큽니다.
- 매일 보는 콘텐츠라 **재방문**을 만듭니다.
- 신한라이프 등 경쟁사 일일운세보다 **정보량을 압도**(12단 구성)하되, 평생운세는 일부러 맛보기만 → 상담으로 유도합니다.

## 어디서 보나요?
`manse.sajuplan.com` → 상단 **"일일운세"** 탭.

## 입력 — 2가지
| 모드 | 설명 |
|---|---|
| **띠로 빠르게** | 12지 띠만 선택. 비회원도 1초. 간단 버전 |
| **생년월일시로 정밀** | 사주 기반 맞춤. 더 정확. 만세력·궁합과 정보 공유 |

## 기간 — 4가지 (입력 후 상단 토글)
| 기간 | 내용 |
|---|---|
| **오늘** | 12단 풍성형(아래) |
| **이번주** | 7일 흐름 그래프 + 분야별 주간 평균 + 가장 좋은/조심할 날 |
| **이번달** | 주차별 흐름 + 이달의 길일/조심할 날 |
| **평생** | 타고난 기질·격국·대운 요약 **맛보기** + "전문가 상담" 유도 (전체 풀이는 상담) |

## "오늘" 화면 구성 (12단 — 경쟁사 이상 정보량)
① 일진 명식 + "오늘은 ○○의 날" + 별명·해시태그 ② 총운(별점·점수·상위%·어제대비) ③ 오늘의 시나리오 ④ 분야별 6개(애정/재물/직장학업/건강/인간관계/이동계약) ⑤ 시간대별(오전/오후/저녁/새벽) ⑥ 이번 주 흐름 그래프 ⑦ 오늘의 주의보 ⑧ 행동 가이드(하면 좋은 것 / 피할 것) ⑨ 행운 6종(색·숫자·방향·시간·아이템·음식) + 잘 맞는 성씨 ⑩ 행운 로또번호 ⑪ 오늘의 띠 궁합 ⑫ 오늘의 명언

> 정밀 모드는 위에 **내 사주 미니 명식**(4기둥+오행)도 함께 + "전체 만세력 보기" 링크.

## 정보 한 번만 — 세 탭이 공유 (세션)
한 번 생년월일시를 넣으면 **만세력·일일운세·궁합**이 같은 사람으로 이어집니다(탭 바꿔도 재입력 X). 궁합은 "나"가 자동 채워지고 "상대"만 넣으면 됩니다.

- **세션 동안만** 유지(새로고침하면 사라짐) — 기기에 개인정보 안 남김.
- **"초기화"** 버튼으로 비움 — 상담사가 하루 수십 명 연달아 볼 때 편합니다.

## 정확하지만, 풀이는 풍성하게
- **일진(오늘 간지)·십성·오행·지지 충합 = 검증된 엔진으로 정확.**
- **점수·문장 = 명리 관계를 매핑한 해석** (마케팅용으로 풍성·단정적, 약간 과장 OK). **같은 입력 + 같은 날짜는 항상 같은 결과**(난수 없음).

## ⛔ 평생운세는 왜 "맛보기"만 주나요?
평생운세 = 상담사가 돈 받고 파는 **핵심 상품**입니다. 무료로 다 주면 상담사 일을 공짜로 대체 → 상담사 이탈. 그래서 **타고난 기질·격국·대운 큰 흐름까지만** 보여주고 "내 평생 사주, 전문가 상담"으로 유도합니다. (메모리 `project_no_ai_saju_analysis` 원칙 — 무료 도구는 맛보기, 완결적 답은 상담으로)

## 이건 정상인가요?
| 상황 | 답변 |
|---|---|
| 띠 모드는 사주 명식이 안 보임 | ✅ 정상. 띠는 간단 버전(생년월일시 넣으면 미니 명식 노출) |
| 같은 날 같은 사람은 운세가 안 바뀜 | ✅ 정상. 결정론적(난수 없음) |
| 평생운세가 요약만 나오고 막혀 있음 | ✅ 정상. 맛보기 + 상담 유도(상담사 보호) |
| 만세력에서 넣은 정보가 일일운세·궁합에 그대로 | ✅ 정상. 세션 공유(편의) |
| 새로고침하면 입력이 사라짐 | ✅ 정상. 세션만 저장(개인정보 안 남김) |
| 로또번호·별명·해시태그가 있음 | ✅ 정상. 바이럴·재미 요소(계산은 정확, 표현만 풍성) |
| 이름이 보라색으로 강조됨 | ✅ 정상. 빨강은 고인 금기라 보라로 (메모리 `feedback_no_red_names`) |
