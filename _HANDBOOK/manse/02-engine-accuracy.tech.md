# [AI 전용] 무료 만세력 계산 엔진 — 정확도/알고리즘 상세

## 설계 원칙

- **천문(절기·삭)은 검증된 알고리즘**(Jean Meeus, Astronomical Algorithms)으로, **명리·만세력 레이어는 직접 구현**.
- 시중 saju 라이브러리 통째 래핑 금지 — 엣지케이스(절입경계·야자시·진태양시·서머타임)에서 제각각 틀림.
- 합격 기준 = 권위 기준값과 일치 (원광/Wikipedia 권위 worked example / 설날).

## 핵심 알고리즘

### 일주 (60갑자 일진)
`dayGanzhiIndex = (지역자정 JDN + DAY_PILLAR_OFFSET) mod 60`. `DAY_PILLAR_OFFSET=49`.
- 검증 앵커: **1949-10-01 = 甲子**, **1592-12-31 = 甲申** (Wikipedia "Sexagenary cycle" worked example). 두 점이 오프셋을 완전 고정.

### 절기 (년주·월주·달력)
태양 겉보기 황경 λ = 15°×k 가 되는 순간. `findSolarTermJD` 뉴턴 반복(λ 변화율 ≈ 0.98565°/일). 입춘=315°, 월지는 315°+30°k 버킷.

### 음력 (`lunar.ts`)
- 삭(신월) JDE: Meeus ch.49 (주요 주기항 + 행성항).
- 음력 달 = 삭~다음 삭, KST 자정 일번호로 환산.
- 동지(270°) 든 달 = 11월. 윤달 = 중기(中氣, 30°배수) 없는 달(삭 시점 황경 30°버킷 미변동).
- 검증: 설날 2024-02-10·2025-01-29·2026-02-17 = 음 1/1, 2000-01-01 = 음 1999.11.25.

### 신강/신약 + 백분위
- 위치가중(월령3·일지2·기타1) 아군(비겁·인성)/적군 합 → ratio(0~1) → 8밴드.
- 득령(월지)·득지(일지)·득세(나머지 과반) 별도 boolean.
- 백분위 = ratio~N(0.5,0.15) 정규분포 가정, 해당 밴드 구간 확률(정규 CDF) → "전체 약 N%가 이 구간 (추정)".

### 합·충·형·파·해·원진 (`hapchung`)
천간합/충, 지지 육합/삼합/충 + 형(삼형 쌍·상형·자형)·파·해·원진 페어 세트 매칭.

### 신살·길성 (25종 — `sinsal()`)
기둥별 지지/천간 매칭. 기준별:
- **일간 기준**: 천을귀인·문창귀인·문곡귀인(문창의 충)·학당귀인(장생지)·금여·태극귀인·홍염살·양인살(양간)·비인살(양인의 충)·건록·암록.
- **년지·일지 삼합 둘 다**: 도화살·역마살·화개살 (둘 다 봐서 풍부, `name:pillar` dedup).
- **년지 방합 기준**: 고신살·과숙살.
- **월지 기준**: 천덕귀인(천간/지지 혼합 타깃)·월덕귀인(삼합국→천간)·천의성(월지 직전 지지).
- **글자 기준**: 현침살(甲辛卯午申)·천문성(戌亥)·역마(사생지 寅申巳亥)·괴강·백호(특정 일주·간지).
- **지지 쌍 기준**: 귀문관살(子酉·丑午·寅未·卯申·辰亥·巳戌)·천라지망(戌亥/辰巳) — 두 기둥 모두 표기.
- 표준 공식 → 위치 정확(`D2` 테스트가 기준 사주 9종 위치 핀). UI(`AnalysisView` 신살·길성 표)가 길성(violet)/흉살(amber) 색 구분 + 기둥별 `<table>`(오행 색)로 렌더.

### 궁합 (`compatibilityScore`)
일간 십성관계 + 일지 육합/충 + 오행 상호보완 + 띠 합충 → 0~100 점 + 등급(참고용).

## 검증

`cd manse && npm test` → vitest 45/45 PASS (D2 = 신살 위치·납음·천을귀인 정확도 핀). 납음 = `((6*천간 - 5*지지) mod 60)` → 30납음 테이블(辛亥=차천금·庚午=노방토). 천을귀인 지지(辛=寅午)·12신살 일지기준(`sinsal12Day`)·자좌운성(`selfStage`)도 노출. 섹션 A(확정명리)·C(일주앵커)·D(분포/신살/신강약/합충/12신살)·E(일진달력·절기)·F(궁합)·G(음력).

## 알려진 한계

1. **음력 경계**: 삭/절기가 자정에 극히 근접한 드문 날은 ±1일 차 가능 → KASI 교차검증 권장.
2. **합반영/조후**: 학파 의존이라 미구현(의도적). 정확도 브랜드 보호.
3. **시주 학파**: 야자시/조자시 옵션(`hourBoundary`) 제공하나 기본 midnight.
4. **서머타임**: 한국 1948~60·87~88 구간 ΔT/표준시 처리 — 해당 출생자 교차검증.
