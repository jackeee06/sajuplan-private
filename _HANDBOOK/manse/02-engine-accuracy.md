# 무료 만세력 정확도는 어떻게 보장하나요?

## 한 줄로 답하면
**계산을 우리가 직접 만들고, "이미 신뢰받는 기준값"과 똑같이 나오는지 자동으로 맞춰봤습니다. 일주·절기·음력까지 검증을 통과했습니다.**

## 왜 정확도가 중요한가요?

전문 상담사는 만세력이 조금만 틀려도 "엉터리네" 하고 떠납니다. 우리가 잡으려는 바로 그 사람들이죠. **정확도가 곧 신뢰이고, 신뢰가 곧 채택**입니다. 그래서 정확도는 우리 만세력의 핵심 무기입니다.

## 무엇을 어떻게 맞췄나요?

| 항목 | 어떻게 정확히 하나 | 검증 |
|---|---|---|
| **일주** (태어난 날 간지) | 60갑자 연속 카운트의 기준점을 권위 자료로 고정 | 1949-10-01=甲子, 1592-12-31=甲申 일치 |
| **년주** | 1월 1일이 아니라 **입춘** 시각 기준 | 천문 계산 |
| **월주** | 24절기 절입 시각 기준 | 천문 계산 |
| **진태양시** | 출생지 경도 + 균시차 보정 | 옵션 제공 |
| **음력** | 외부 데이터 없이 **천문으로 직접 계산** (삭·절기) | 설날 2024·2025·2026 = 음력 1월 1일 일치 |
| **절기** | 태양 황경 직접 계산 | 달력에 표시 |

→ 전체 자동 검증 **43개 항목 모두 통과** (신살 위치 정확도 핀 포함).

## 어디까지 믿어도 되나요?

- 일반적인 출생일(1900~2050년대)의 **년·월·일·시주**는 신뢰해도 됩니다.
- **음력·절기**도 검증된 천문 계산입니다.
- 단, 절기·음력이 **자정·자시 등 경계에 아슬아슬하게 걸리는 극히 드문 경우**는 분 단위까지 한 번 더 확인하는 게 안전합니다.

## 신살·길성은 푸짐하게 (마케팅 도구 — 2026-06-24)

이 페이지는 유입·홍보 도구라 **정보는 경쟁사보다 많고 푸짐하게** 보여줍니다. 신살·길성을 **25종**까지 늘리고, 어느 기둥(년·월·일·시)에 붙는지 **표로** 보여주며 길성(보라)·흉살(주황)을 색으로 구분합니다.

| 종류 | 항목 |
|---|---|
| **길성(吉) 12** | 천을귀인·천덕귀인·월덕귀인·태극귀인·문창귀인·문곡귀인·학당귀인·금여·천의성·천문성·건록·암록 |
| **신살(煞) 13** | 도화살·홍염살·역마살·화개살·양인살·현침살·백호살·괴강살·비인살·고신살·과숙살·귀문관살·천라지망 |

- **도화·역마·화개**는 일지뿐 아니라 **년지 기준도 함께** 봅니다(전통 관례 — 더 정확·풍부). 역마는 사생지(寅申巳亥) 글자 자체도 포함.
- ⚠️ **양은 푸짐하게, 위치 계산은 정확하게** — 신살이 어느 기둥에 붙는지는 표준 공식으로 정확히 냅니다(상담사가 매일 쓰는 도구라 위치가 틀리면 안 됨). 과장은 풀이 표현·커버리지에서.

## 양은 푸짐하게, 단 이런 건 신중하게

> 정보량·풀이는 푸짐하게 제공하되, 아래 **학파마다 답이 갈리는 계산 토글**과 **근거 없는 수치 단정**만은 신중히 다룹니다 — 양의 문제가 아니라 신뢰의 문제라서요.

| 신중하게 다루는 것 | 이유 |
|---|---|
| 합반영 / 조후 보정 토글 | **학파마다 정답이 다른** 논쟁적 옵션. 어설프게 흉내 내면 신뢰가 깨짐 |
| "상위 N%" 단정 | 통계 근거 없는 단정은 금지. 대신 분포 모델 **추정값 + "(추정)" 라벨** |
| 건강/직업 단정 풀이 | 추측을 사실처럼 단정 금지. "참고용" 해석으로 분리 |

## 이건 정상인가요?

| 상황 | 답변 |
|---|---|
| 같은 생일인데 다른 만세력과 시주가 다름 | ⚠️ 진태양시 보정 on/off, 야자시 처리(학파) 차이일 수 있음 |
| 음력 날짜가 다른 앱과 하루 다름 | ⚠️ 경계 케이스 가능. 천문연구원 값과 교차 확인 |
| "오늘의 운세"가 없음 | ✅ 정상. 만세력 도구라 미포함 |
