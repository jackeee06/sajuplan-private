# 무료 만세력 (마케팅 유입 도구)

## 한 줄로 답하면
**`manse.sajuplan.com` 에 있는 무료 만세력. 사주플랜 본 서비스와 코드가 분리된 독립 제품이지만, 우리가 만든 "유입 깔때기" 마케팅 도구입니다.**

## 무엇인가요 — 왜 만들었나요?

생년월일시만 넣으면 사주 명식·해석을 무료로 보여주는 도구입니다. 목적은 세 가지:

1. **검색 유입** — "무료 만세력"은 검색량이 큰 키워드. 광고비 없이 매일 들어오는 자연 유입.
2. **상담사 책상 상주** — 만세력은 사주 상담사가 매일 켜는 작업 도구. 쓸 만하면 경쟁사 소속 상담사도 우리 걸 띄워둠 → 브랜드 노출 + 상담사 모집 깔때기.
3. **상담 전환** — 결과 화면에서 "이 사주, 전문가에게" → 사주플랜 상담으로 연결.

## 어디서 보나요?

| 항목 | 주소 |
|---|---|
| 무료 만세력 | **https://manse.sajuplan.com** |

PC·모바일 모두 지원(화면 폭에 따라 자동 전환). 로그인 없이 바로 사용.

> **사주플랜 앱/웹 홈에서 진입 (2026-06-25)**: 홈 상단(통계카드 아래·상담사 탭 위)에 "무료 만세력·운세" 슬림 바(四柱+무료 뱃지, 부제 "사주팔자·오늘의 운세·궁합 모두 무료로"). 탭하면 **외부 모바일웹**으로 manse.sajuplan.com이 열립니다(앱 안이면 외부 브라우저 — `openExternalUrl`). → 상담사가 상담(앱)과 만세력(브라우저)을 번갈아 참고 가능.
> **기본 화면 규칙**: 앱에서 **상담사**가 누르면 `?view=pro`(폰이든 PC든 **전문가 보기**), **회원·일반**은 쉽게 보기. 검색·직접 방문(신호 없음)은 폰=쉽게/PC=전문가 + **마지막 선택 기억**(localStorage `manse_view`). 어느 쪽이든 상단 토글로 즉시 전환.
> ⛔ "AI 사주분석"은 상담사와 경쟁이라 의도적으로 미탑재 (메모리 `project_no_ai_saju_analysis`).

## 무슨 기능이 있나요?

- **사주 원국** — 년·월·일·시주(천간/지지), 십성·지장간·12운성
- **격국 · 신강/신약 · 용신** — 강약 곡선 + 득령/득지/득세 + 백분위(추정)
- **오행 분석** — 도넛 차트 + 과다/부족 + 오행 관계도(상생·상극 오각형)
- **십성 분석** — 도넛 + 분포
- **신살 · 길성** — 천을귀인·도화·역마 등 + 의미 설명
- **사주 관계** — 합·충·**형·파·해·원진** + 12신살 (원국 위 탭으로 강조해서 봄)
- **운의 흐름** — 대운 → 연운 → 월운 **클릭 드릴다운** (대운 누르면 그 10년, 연운 누르면 그 해 12개월)
- **일진 달력** — 날짜별 일진 + **음력 + 절기** (천문 계산)
- **분야별 풀이** — 직업·애정·재물·건강 (대중용 해석)
- **궁합** — 두 사람 사주 매칭 점수·해석
- **일일운세** — 오늘·주간·월간·평생운세 (별점·분야별·행운·로또·띠궁합). 상단 "일일운세" 탭 → [일일운세](manse/04-daily-fortune)
- **공유** — 결과 공유(카톡 OG 링크 카드)

> 화면·조작 상세(인터랙티브 원국·운의 흐름·가독성·공유): [무료 만세력 화면·UX](manse/03-chart-ui)

## 사주플랜과의 관계 — "코드는 분리, 안전"

> ⚠️ 만세력은 사주플랜과 **코드가 섞이지 않은 독립 제품**입니다. 회원·코인·결제 데이터에 **접근하지 않습니다.**

- 의존성은 **단방향**: 사주플랜이 만세력을 가져다 쓸 수 있어도, 만세력은 사주플랜을 모릅니다.
- 그래서 만세력 트래픽이 폭증해도 **사주플랜 본 서비스(결제·상담·돈)는 안 흔들립니다.**
- 타사 사이트·랜딩페이지에도 끼워 쓸 수 있는 구조.

## 정확도가 무기입니다

포스텔러 같은 기존 만세력과의 차별점은 **검증된 정확도**입니다.

- **일주(태어난 날 간지)** — 권위 기준일로 검증
- **절기·진태양시** — 천문 계산
- **음력** — 외부 데이터 없이 천문으로 직접 계산 (설날로 검증)
