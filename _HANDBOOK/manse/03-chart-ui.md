# 무료 만세력 화면·UX (사주판·운의 흐름·공유)

## 한 줄로 답하면
**원국(사주판) 하나에서 탭으로 합·충·공망을 강조해 보고, 대운→연운→월운을 클릭으로 파고들며, 결과를 카톡으로 공유한다. 중장년·상담사 모두 읽기 쉽게 한자에 한글 음을 달고 글자를 키웠다. (2026-06-24 개편)**

## 무엇이 바뀌었나

### 1. 인터랙티브 원국 — 탭이 곧 리모컨
- 예전엔 사주판 아래에 같은 내용(천간/지지/십성)을 한 번 더 보여주는 "자세히 보기 표"가 따로 있어 헷갈렸음.
- 지금은 **원국 하나**에 궁성·의미 줄까지 합치고, 위의 탭을 누르면 **해당 칸이 핑크로 강조 + 나머지는 흐려지고(dim) + 아래에 한 줄 설명·관계 칩**이 뜸.
- 탭 종류: `궁성 / 천간합 / 지지육합 / 지지삼합 / 지지방합 / 천간충 / 지지충 / 공망 / 형 / 파 / 해 / 원진`.
- 관계가 없으면 흐려지지 않고 "이 사주엔 ○○ 관계가 없습니다".
- **공망**은 탭과 무관하게 항상 해당 지지에 핑크 "공" 뱃지·테두리로 표시(상담사가 한눈에).

### 2. 운의 흐름 — 대운 → 연운 → 월운 드릴다운
- **대운 칸을 누르면** 그 대운의 10년치 연운으로 바뀌고, **연운(연도)을 누르면** 그 해 12개월 월운으로 바뀜.
- 접속하면 **현재 나이의 대운 + 올해**가 자동 선택돼 바로 유용.
- 상단에 경로 표시(`대운 戊寅(33~42세) › 2026년`).

### 3. 읽기 쉽게 — 중장년·상담사 배려
- **한자 굵게**: 한자 전용 웹폰트(Noto Sans KR) 로드. Pretendard엔 한자 글자가 없어 굵기가 안 먹던 문제를 해결.
- **노안 배려**: 루트 글자 크기를 키워 설명·라벨·여백이 비율 그대로 커짐.
- **한글 음 병기**: 한자마다 옆에 한글 음(壬→임, 申→신)을 또렷이 — 한자를 몰라도 읽힘.
- **오행 범례**: 배경색이 무슨 기운(목·화·토·금·수)인지 원국·운의흐름 아래에 상시 표시.

### 4. 입력·공유
- **입력 접힘**: "만세력 보기"를 누르면 입력창이 접히고 결과만 보임. 프로필 옆 "✏️ 정보 수정하기"로 다시 펼침(이전 입력값 보존). **정보는 세션 동안 만세력·일일운세·궁합이 공유**(탭 바꿔도 재입력 X, "초기화"로 비움 — 2026-06-25).
- **결과 공유**: 카톡 등에 OG 미리보기 카드(썸네일 + 제목/설명)로 전송. 링크에 생년월일·이름이 담겨, 받은 사람이 열면 그 사주가 자동 계산돼 표시. (옛 "이미지 공유"는 캡처 버그로 제거, "링크 공유" → "결과 공유" 로 단일화 — 2026-06-25)

### 5. 신살·길성 — 정보량을 경쟁사 이상으로 (2026-06-24)
- 예전 칩 나열 → **기둥별 표**(시/일/월/년 × 천간·지지·신살)로 바꿔 한눈에 들어오고 "있어 보임".
- **신살·길성 25종**으로 확대(천덕귀인·월덕귀인·금여·태극귀인·문곡귀인·천의성·천문성·현침살·홍염살·비인살·고신살·과숙살·귀문관살·천라지망 등 추가) + 상단 요약 칩 + "총 N개·길성·신살" 카운트.
- **길성은 보라, 흉살은 주황** 색 구분 + 신살마다 한 줄 풀이.
- 도화·역마·화개는 년지·일지 둘 다 기준(전통) → 같은 사주에서 경쟁사와 동일하게 나오고, 다른 사주에선 우리가 더 많이.

### 6. 오행·십성 분석 강화 (2026-06-24)
- **십성 10종 전부** 막대그래프로 표시(0% 포함, 흐리게) — 예전엔 보유한 것만 보여 빈약했음.
- **십성 5그룹 요약**(비겁·식상·재성·관성·인성 %) + **십성마다 한 줄 뜻풀이** 추가 → 경쟁사(10행 %표만)보다 풍부.
- 오행 분포는 도넛 + 막대(%+부족/적정/발달/과다 등급) + 오각형(상생/상극·십성역할·%)으로 이미 경쟁사 이상.

## 이건 정상인가요?

| 상황 | 답변 |
|---|---|
| 십성에 0%(식신·정재 등)도 보임 | ✅ 정상. 10종 전부 표시해 완전하게 (경쟁사 이상) |
| 쉽게 보기에도 풀이가 길게 나옴 | ✅ 정상. 일반인용으로 일간 성향·오행·신강약·지금 대운·분야별 장문풀이·주요 신살까지 담음 (2026-06-24) |
| 전문가 보기 원국 아래에 납음·관계·신살·12신살이 다 펼쳐짐 | ✅ 정상. 상담사 요청 — 전문가 보기는 접지 않고 전부 노출(2026-06-25). 쉽게 보기는 그대로 깔끔 |
| 신살이 표로 나오고 경쟁사만큼/더 많음 | ✅ 정상. 정보량을 경쟁사 이상으로 푸짐하게 (마케팅 도구) |
| 사주판 아래에 있던 "자세히 보기 표"가 사라짐 | ✅ 정상. 원국 하나로 합쳐 중복 제거 |
| 탭을 누르면 일부 칸이 흐려짐 | ✅ 정상. 관계되는 칸만 강조하고 나머지는 dim |
| 卯 등에 핑크 "공" 뱃지·테두리 | ✅ 정상. 공망(비어 있는 자리) 표시 |
| 한자 옆 작은 한글 글자 | ✅ 정상. 음(독음) 병기 — 접근성 |
| "명조 저장" 버튼이 없음 | ✅ 정상. 익명 저장은 제거(불특정다수 불필요·상담사 방해). 진짜 저장은 회원 연동 단계에서 |
| "이미지 공유" 버튼이 없음 | ✅ 정상. 캡처 버그로 제거(2026-06-25). "결과 공유"(링크/OG 카드)만 유지 |
