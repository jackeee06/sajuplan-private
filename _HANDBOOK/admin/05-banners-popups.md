# 배너·팝업 관리

## 한 줄로 답하면
**회원 화면 상단 배너 (홈) + 진입 시 팝업 레이어. 운영자가 등록·기간·노출 위치 설정.**

## 종류

### 홈 배너
- Home 페이지 상단 슬라이드
- 마케팅·이벤트 안내용
- 자동 슬라이드 (3-5초)

### 팝업 레이어 (2026-06-12 사용자 노출 완성)
- 사주플랜 **홈 진입 시 + 상담사 마이페이지 진입 시** 자동 노출 (모달)
- "오늘 하루 보지 않기" / "닫기" 옵션
- **대상 구분**: 전체 / 회원만 / 상담사만 (등록 시 선택)
- **본문 에디터**: 공지·이벤트와 동일한 글쓰기 에디터 (굵게·이미지·링크)
- 노출 제한: "오늘 하루 보지 않기" 누르면 그 팝업은 설정 시간 동안 안 보임 (사용자 기기에 기억)

> ⚠️ **역사 메모**: 2026-06-12 이전엔 관리자가 팝업을 등록해도 **고객 화면에 안 떴다** (사용자 노출 기능 자체가 없었음). 이날 사용자 노출 API·렌더·대상 구분·에디터를 신설해 "등록 → 즉시 고객 화면 노출"이 처음으로 작동한다.

### 시스템 배너 (별도)
- 점검 안내 (노랑)
- 단골 상담사 접속 (핑크)
- 상담사 incoming 채팅 (핑크)
- → 운영자가 직접 만들지 않고 시스템 상태 따라 자동

## 이런 상황을 보셨나요?

### "이벤트 배너 새로 올리고 싶어요"

→ 사이드바 → 기타 → 배너관리 → 새 배너 등록. 이미지·기간·링크 입력. 활성 토글로 즉시 노출.

### "팝업 너무 자주 떠요"

→ 팝업 노출 정책 (예: 1일 1회 / 7일 1회) 설정. 사이드바 → 기타 → 팝업레이어 관리.

### "회원에게만 / 상담사에게만 팝업 띄우고 싶어요"

→ 팝업 등록 시 **대상** 선택: 전체 / 회원만 / 상담사만.
- **전체**: 비로그인 포함 모두 (홈)
- **회원만**: 로그인한 회원 (홈) — 비로그인엔 안 뜸
- **상담사만**: 상담사 계정 (상담사 마이페이지) — 회원·비로그인엔 안 뜸

### "팝업 본문을 예쁘게(굵게·이미지) 쓰고 싶어요"

→ 등록 폼 본문은 글쓰기 에디터(공지·이벤트와 동일). 굵게·이미지·링크 넣어 작성하면 그대로 노출된다. (노출 시 악성코드는 자동 정화 → [콘텐츠 XSS 정화](system/11-content-sanitization))

### "배너 잘못 올라갔어요 (실수)"

→ 즉시 사이드바 → 기타 → 배너관리 → 비활성 토글. 캐시 갱신은 사용자별 시간 차이 있음.

## 이건 정상인가요? 에러인가요?

| 상황 | 답변 |
|---|---|
| 등록 → 즉시 회원 화면 노출 | ✅ 정상 |
| 기간 종료 → 자동 숨김 | ✅ 정상 |
| 사용자가 "오늘 하루 보지 않기" → 일정 시간 숨김 | ✅ 정상 |
| "회원만" 팝업이 비로그인엔 안 뜸 | ✅ 정상 (대상 규칙) |
| "상담사만" 팝업이 홈엔 안 뜨고 상담사 마이페이지에만 | ✅ 정상 (대상+위치 규칙) |
| 비활성 토글했는데 일부 사용자에게 보임 | ⚠️ 브라우저 캐시. 시간 지나면 갱신 |
| 외부 URL 클릭이 안 됨 (WebView 한계) | ⚠️ openExternalUrl() 호출 필요 |

## 운영자가 확인하는 위치

| 확인 항목 | 메뉴 위치 |
|---|---|
| 배너 등록·관리 | 사이드바 → 기타 → 배너관리 |
| 팝업 레이어 관리 | 사이드바 → 기타 → 팝업레이어 관리 |
| 사주메인 (홈 구성) | 사이드바 → 기타 → 사주메인관리 |
