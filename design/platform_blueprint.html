배포 명령
"fast패치" 키워드 = 아래 명령 즉시 실행 · 다른 방법 없음
변경 내용 명령어
사용자 프론트 변경 시
web/user/ 소스 수정 후		 python tools/_patch_frontend_fast.py user
관리자 프론트 변경 시
web/mng/ 소스 수정 후		 python tools/_patch_frontend_fast.py mng
API 코드 변경 시
api/src/ 소스 수정 후		 python tools/_patch_api.py
핸드북 MD 변경 시
_HANDBOOK/*.md 수정 후		 python tools/_sync_handbook.py
배포 후 반드시 확인: __SAJUMOON_ENV__ → prod 치환 여부. 누락 시 prod가 test API를 호출하는 사고 발생 (실 사고 이력 있음)
🚨
절대 해서는 안 되는 것 (핵심 안전 원칙)
실제 사고 이력 기반 — 반드시 숙지
1
DB 직접 삭제·TRUNCATE 절대 금지 — FK cascade 사고 이력 있음. soft delete 정책(state='deleted') 준수. pg_dump 백업 후 화이트리스트 작업만 허용.
2
__SAJUMOON_ENV__ 치환 누락 배포 금지 — 누락 시 prod가 test API를 호출. 실 사고 발생 이력. 배포 스크립트가 자동 처리하나 수동 배포 시 주의.
3
/data/wwwroot/sajuplan.com/에 배포 금지 — nginx 미사용 죽은 폴더. 여기에 배포하면 사용자에게 아무 반영 없음.
4
m2net / AG9 / BizM 외부 서비스 키 임의 수정 금지 — 실 서비스에 즉각 영향. 변경 시 반드시 사장님과 사전 협의.
5
결제·정산 관련 코드 변경 시 E2E 0 failed 필수 확인 — Playwright 자동 클릭 테스트 통과 후에만 완료 보고. 코드 리뷰만으로는 불충분.
