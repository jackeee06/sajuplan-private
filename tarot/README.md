# 🔮 타로 (Tarot) — 독립 제품

전화타로 상담의 **공유 타로보드** + **독립 마케팅 타로**. 사주플랜과 **코드 분리·단방향 의존**(만세력과 동일 구조).
사주플랜 → 타로(임베드)만 가능. 타로는 회원DB·코인·상담을 **모른다** → 타사 임베드·별도 서브도메인 가능.

## 구조 (monorepo)

```
packages/
  engine/  @tarot/engine   순수 함수 — 덱 78장·스프레드 6종·셔플·정역방향·세션 상태머신. 의존성 0(왕관 보석)
  api/     @tarot/api        라이브 동기화(방코드 페어링·WebSocket 중계) + 외부 임베드 창구
  web/     @tarot/web        독립 프론트 — 타로보드 화면
```

## 운영 모드 3종 (1코드 2용도)

- **(A) 독립 마케팅** — 누구나 혼자 "오늘의 타로/흐름" 무료(맛보기). SEO·바이럴·앱 유입. 동기화 없음(LocalTransport).
- **(B) 라이브 상담** — 전화타로 중 상담사↔고객 같은 화면. WebSocket(LiveTransport).
- **(C) 임베드/타사** — 외부 사이트 끼워넣기(API 키). 먼 미래.

> **안전선**: 무료 타로도 맛보기(카드+키워드+한 줄)까지만. 깊은 풀이는 상담사 유도. (앱이 완결 해석 출력 금지 — 상담사 가치 보존)

## 개발

```bash
cd tarot
npm install
npm run test       # 엔진 검증(78장 무결성 · 셔플 결정론 · 상태머신)
npm run build      # 엔진 빌드
```
